# Validação F196 — runbook reproduzível para carregar o coletor Overwolf

Foi adicionado `scripts/Start-OverwolfCollectorDev.ps1`. O script:

- valida o pacote com `Test-CollectorPackage.ps1` antes de abrir o cliente;
- detecta a instalação padrão do Overwolf;
- pode iniciar o cliente com `-EnableDevTools`;
- não tenta contornar whitelist, autenticação ou o fluxo oficial de **Load
  unpacked extension**;
- imprime o caminho exato que deve ser selecionado.

Uso:

```powershell
pwsh -File .\scripts\Start-OverwolfCollectorDev.ps1 -Launch -EnableDevTools
```

Depois, no Overwolf, selecione `artifacts/collector-overwolf` em Development
Options e abra `My Frame Collector Dev`.

O fluxo segue a documentação oficial de carregamento de extensões unpacked:
<https://dev.overwolf.com/ow-native/getting-started/onboarding-resources/basic-sample-app/>

- [x] Pacote validado antes da abertura.
- [x] Caminho de seleção impresso sem depender de AlecaFrame.
- [x] DevTools opcional, sem alterar whitelist ou credenciais.
- [ ] Extensão carregada e captura real (gate manual F1).
