# F222 — exportação de diagnóstico sanitizado na UI

## Objetivo

Entregar a ação prevista na página de sincronização para compartilhar estado
operacional sem expor dados privados.

## Implementação

O botão **Copy diagnostics** copia JSON versionado contendo apenas estados de
fontes, revisões, parser, cobertura e tentativas recentes. Payloads de inventário,
tokens, username e caminhos locais não são incluídos. Falhas de leitura aparecem
na mensagem da UI e são registradas apenas no logger local.

## Validação

`MyFrame.App` compilou para `net10.0-windows10.0.19041.0/win-x64` com exit code 0.
Os avisos NU1900 são do proxy/NuGet indisponível; os avisos XAML existentes não
impedem o build.
