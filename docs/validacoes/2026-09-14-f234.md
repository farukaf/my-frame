# F234 — verificador do contrato das skills

## Objetivo

Transformar as novas pré-condições de captura em uma verificação repetível,
sem depender de PyYAML ou de um cliente LLM.

## Implementação

`scripts/Test-SkillsContract.ps1` valida o contrato comum e as skills
`warframe-builds`/`warframe-farm`, incluindo versão 4, `get_capture_inbox_status`,
`state=ready`, heartbeat fresco, marcador válido e saída `unverified`.

## Validação

- script executado com sucesso: `SKILLS_CONTRACT_OK=1`;
- nenhuma rede, credencial ou escrita externa é usada;
- substitui a validação automática indisponível quando o módulo Python `yaml`
  não está instalado.
