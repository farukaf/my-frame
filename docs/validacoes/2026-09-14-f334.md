# F334 — auditoria de logs do preflight F1

O diretório local de logs do Overwolf contém registros de apps instalados, inclusive AlecaFrame,
mas não contém uma entrada do `my-frame`/coletor unpacked. Também não foi encontrado listener
local de DevTools para carregar a extensão por automação.

Evidência atual do probe:

```text
OVERWOLF_COLLECTOR_READY=0
heartbeatFresh=false
validMarkers=0
OVERWOLF_ACTION=load-unpacked-extension
```

Isso confirma que a ausência de captura não é um erro de parser ou de marker: a extensão ainda
não foi carregada no Overwolf. Logs de AlecaFrame não são aceitos como evidência F1.
