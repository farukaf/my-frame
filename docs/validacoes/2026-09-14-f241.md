# F241 — atualização do dashboard após importação Overwolf

## Alteração

Após uma importação aceita pelo inbox, `DashboardViewModel` agora executa uma
atualização do snapshot do dashboard. O painel de sincronização continua sendo
atualizado para todas as tentativas; a atualização pesada só ocorre quando há
captura nova (`Imported > 0`).

## Validação

- App Windows `net10.0-windows10.0.19041.0/win-x64`: build aprovado;
- captura rejeitada ou já publicada não força reconstrução desnecessária;
- captura importada passa a refletir inventário/recomendações sem clique extra.
