# Validação F152 — sincronização World State por arquivo local

`MyFrame.Sync --world-state-file <arquivo.json>` publica um World State baixado
localmente usando o mesmo parser e as mesmas tabelas SQLite do endpoint oficial.
Bounties, jobs, rewards, ciclos, hash, revisão e coverage continuam sujeitos às
validações existentes; a procedência fica marcada como `worldstate-file-1`.

O arquivo é limitado a 32 MiB e precisa ser um objeto JSON compatível com o
contrato World State. Isso permite operar em redes que bloqueiam o endpoint sem
usar fonte AlecaFrame ou transformar payload inválido em estado vazio.
