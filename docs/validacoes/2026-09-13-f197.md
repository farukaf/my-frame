# Validação F197 — ingestão de referência Overframe no SyncHost e MCP

Foi adicionado `scripts/Test-ReferenceSyncInspector.ps1`, que executa o fluxo
com os binários distribuídos:

1. cria um documento Overframe HTTPS em data root temporário;
2. importa com `MyFrame.Sync --reference-file`;
3. consulta `search_references` pelo MCP Inspector;
4. remove o data root ao terminar.

Resultado observado:

```text
importState=imported
referenceState=available
documents=1
rejectedDocuments=0
hitKind=Overframe
hitLicense=community
hitAuthor=tester
trustedForFacts=False
```

A referência é pesquisável, mas permanece conteúdo comunitário não confiável
para fatos (`trustedForFacts=false`). O parser também mantém a validação de host
e HTTPS, impedindo que um arquivo de outro domínio seja tratado como Wiki ou
Overframe.

## Critérios

- [x] Ingestão independente do AlecaFrame.
- [x] Busca MCP no pacote distribuído.
- [x] Autoria, licença, tipo e revisão preservados.
- [x] Conteúdo comunitário isolado de fatos confiáveis.
- [x] Data root temporário removido após o smoke.
- [ ] Sincronização online periódica com autorização/licença formal das fontes.
