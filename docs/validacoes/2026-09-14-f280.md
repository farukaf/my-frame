# F280 — resultado rico para busca do Public Export

## Objetivo

Permitir que a LLM consulte o catálogo oficial sem depender de inventário para
obter os dados necessários a uma recomendação: categoria técnica, receita,
mercado e fontes de relíquia.

## Alteração

A ferramenta search_public_export agora retorna, por item:

- productCategory, itemType, imagem e flags masterable, prime, tradable
  e vaulted;
- identidade marketId/marketSlug;
- componentes normalizados da receita;
- fontes de relíquia observadas;
- aliases localizados já persistidos.

O JSON bruto continua fora da resposta. O mapper compartilhado do Core é usado
para manter a mesma normalização da leitura SQLite.
