# F65 — distribuição Windows 0.0.7

## Evidência executada

```text
scripts/Build-Distribution.ps1 -Version 0.0.7 -Configuration Release -RuntimeIdentifier win-x64
→ artifacts/MyFrame-0.0.7-win-x64
```

O artefato contém `MyFrame.App.exe` e `MyFrame.Mcp.exe`. O smoke executado
contra o executável distribuído retornou:

```text
MCP_READONLY_OK=1
MCP_EXIT=0
Collector package valid: MyFrame.Collector.Overwolf
```

O build terminou com 0 erros, mas emitiu 180 warnings de bindings XAML
(`XC0022`/`XC0025`). Eles não foram ocultados nem convertidos em aprovação de
qualidade zero-warning; ficam como dívida de performance/limpeza da UI.
