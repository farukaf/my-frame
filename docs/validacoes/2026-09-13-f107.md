# F107 — schemas MCP nullable portáveis

F106 encontrou 163 avisos no MCP Inspector porque o contrato emitia nullable
como `type: ["T", "null"]`. A transformação de schema agora usa
`UseNullableKeyword`, mantendo a semântica nullable com a forma que clientes
MCP mais restritivos reconhecem.

## Evidência

```text
MCP_INSPECTOR_OK=1
MCP_INSPECTOR_TOOLS=14
MCP_INSPECTOR_WARNINGS=0
MCP_INSPECTOR_ERRORS=0
MCP_INSPECTOR_METHOD=tools/list
```

Também foi adicionado um teste unitário que percorre schemas de entrada e saída
de todas as ferramentas e rejeita qualquer propriedade `type` emitida como array.

```text
Passed: 1, Failed: 0, Skipped: 0
```
