# F78 — adaptador World State oficial

F78 torna `https://content.warframe.com/dynamic/worldState.php` a URL padrão do
cliente e mantém `https://api.warframestat.us/pc` como fallback configurável. O
parser agora aceita os aliases PascalCase usados no payload oficial, datas BSON
`$date/$numberLong`, tags de sindicato e ciclos sem quebrar o contrato comunitário.

o registro permanece sem `Rewards` e a cobertura `bountyRewards`/`motherTokens`
fica `NotObserved`; nenhum nome ou quantidade é inventado.
