# F261 — comparação segura entre snapshots do inventário

Foi adicionada a ferramenta read-only `get_inventory_changes`. Ela compara duas
revisões completas, retorna apenas alterações de equipamento/quantidade e não
expõe payload bruto. Se uma das revisões for `delta`, o estado é `partial` e
nenhuma adição/remoção é inferida; sem histórico suficiente, o estado é
`insufficient_history`.

Validação: build MCP, teste sem dados (`not_initialized`) e contrato read-only
aprovados.
