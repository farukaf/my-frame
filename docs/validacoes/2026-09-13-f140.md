# Validação F140 — runbook de agendamento Windows

`scripts/Register-MyFrameSyncTask.ps1` registra, remove ou simula a tarefa
Windows que chama `MyFrame.Sync --all`. A tarefa usa o usuário interativo atual,
privilégio mínimo, não sobrepõe uma execução em andamento e começa disponível
quando o computador retorna.

Exemplos:

```powershell
pwsh -File .\scripts\Register-MyFrameSyncTask.ps1 `
  -SyncExecutable .\artifacts\MyFrame-0.0.9-win-x64\MyFrame.Sync.exe `
  -Frequency Hourly -WhatIf

pwsh -File .\scripts\Register-MyFrameSyncTask.ps1 `
  -SyncExecutable .\artifacts\MyFrame-0.0.9-win-x64\MyFrame.Sync.exe `
  -Frequency Hourly

pwsh -File .\scripts\Register-MyFrameSyncTask.ps1 `
  -SyncExecutable .\artifacts\MyFrame-0.0.9-win-x64\MyFrame.Sync.exe `
  -Unregister
```

O agente não executa o registro automaticamente; `-WhatIf` foi usado para
validar a construção da tarefa sem alterar o Agendador do Windows.
