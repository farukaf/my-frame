# F247 — verificador reproduzível do gate F1

Foi adicionado `scripts/Wait-OverwolfCollectorReady.ps1`. O verificador apenas
consulta `MyFrame.Sync --overwolf-inventory-probe`, imprime campos sanitizados e
termina com sucesso somente quando o estado é `ready`, o heartbeat é fresco e há
ao menos um marcador válido.

Uso durante a homologação:

```powershell
pwsh -File .\scripts\Wait-OverwolfCollectorReady.ps1 -TimeoutSeconds 600
```

Enquanto o comando aguarda, carregar `artifacts/collector-overwolf` como extensão
unpacked no Overwolf e iniciar a captura. Timeout retorna código 2 e não é tratado
como evidência positiva.
