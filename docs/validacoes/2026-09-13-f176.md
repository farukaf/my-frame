# Validação F176 — instalação limpa e upgrade side-by-side do pacote F175

## Smoke de instalação limpa

```powershell
pwsh -NoProfile -File .\scripts\Test-McpCleanInstall.ps1 \
  -ServerPath .\artifacts\MyFrame-0.0.6-win-x64\MyFrame.Mcp.exe
```

Resultado:

```text
MCP_CLEAN_INSTALL_OK=1
MCP_CLEAN_SETUP_REQUIRED=1
MCP_CLEAN_LEGACY_FILES=0
MCP_CLEAN_SQLITE=1
MCP_CLEAN_EXIT=0
```

O MCP distribuído criou apenas o banco SQLite no data root temporário,
reportou `SETUP_REQUIRED` e não recriou arquivos legados. O Inspector foi
baixado durante a execução com acesso ao registry npm.

## Smoke de upgrade

```powershell
pwsh -NoProfile -File .\scripts\Test-DistributionUpgrade.ps1 \
  -OldDistributionPath .\artifacts\MyFrame-0.0.5-win-x64 \
  -NewDistributionPath .\artifacts\MyFrame-0.0.6-win-x64
```

Resultado:

```text
DISTRIBUTION_UPGRADE_OK=1
DISTRIBUTION_UPGRADE_MODE=side-by-side
```

As duas versões iniciaram simultaneamente, permaneceram ativas durante a
verificação e encerraram por EOF sem escrever no data root limpo.

- [x] Instalação limpa do MCP distribuído.
- [x] Aviso de configuração inicial preservado.
- [x] Ausência de arquivos legados.
- [x] Upgrade side-by-side entre versões publicadas.
- [ ] Instalação gráfica em máquina Windows separada.
