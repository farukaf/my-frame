# F70 — UX de importação legada opcional

F70 alinha a interface ao desenho SQLite-first: a seção de pasta agora se
chama `Legacy AlecaFrame import (optional)`, os botões deixam claro que são
para escolher/limpar uma pasta legada, e as mensagens informam que o SQLite
sincronizado permanece primário.

## Validação

- build MyFrame.App sem erros;
- Core 142/142, incluindo o caminho vazio do adaptador legado;
- comandos existentes continuam funcionais para migração opt-in;
- caminho legado vazio é aceito pelo adaptador sem lançar exceção no startup;
- nenhuma mensagem de inicialização apresenta AlecaFrame como requisito quando
  existe projeção SQLite.
