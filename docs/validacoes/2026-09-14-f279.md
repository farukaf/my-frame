# F279 — gate offline Public Export empacotado

## Objetivo

Provar o caminho completo de dados quando o host oficial está indisponível:
snapshot JSON local → `MyFrame.Sync` → SQLite → MCP `search_public_export`.

## Alteração

Foi adicionada uma fixture mínima com nomes EN/PT, componente de receita e
metadados técnicos, além do script `scripts/Test-PublicExportOffline.ps1`. O
script seleciona a distribuição mais recente, publica o arquivo por
`--public-export-file` e consulta o executável MCP via Inspector. A fixture é
descartada junto do banco temporário ao fim do teste.

## Validação

```text
importState=published
importedRecords=1
mcpState=published
mcpItems=1
itemName=Test Weapon
localizedNames=Known
technicalMetadata=Known
activeRevision=<id da revisão SQLite>
```

O gate não acessa rede, não lê AlecaFrame e não deixa banco ou payload fora do
diretório temporário.
