# F31 — fluxo ponta a ponta sintético

F31 adiciona duas verificações de integração:

1. O teste da inbox importa uma captura `.ready.json`, confirma idempotência e
   lê a mesma revisão via `SqliteSynchronizedDataReader`.
2. O teste MCP stdio faz uma chamada real a `get_inventory_coverage`, além da
   descoberta de schema, e exige `structuredContent` sem erro.

O fluxo cobre transporte, validação, publicação e leitura compartilhada sem
usar rede ou dados pessoais. Ele é uma prova sintética do encadeamento local;
captura GEP real continua sendo o gate F1 separado.
