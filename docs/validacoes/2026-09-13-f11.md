# F11 — página visual de status de sincronização

## Entrega

A aplicação agora possui a seção **Sync status**, que lê o mesmo
`MyFrameStoragePaths.DataDatabasePath` usado pelo MCP. O leitor abre o SQLite
em modo somente leitura através de `SyncDatabase.GetStatusAsync` e exibe, por
fonte:

- estado (`published`, `failed`, `not_initialized` ou `unknown`);
- contagens aceitas/rejeitadas;
- revisão ativa;
- horário da última execução;
- mensagem de erro sem payload bruto.

O status é carregado mesmo quando o diretório legado do AlecaFrame ainda não foi
configurado. A página não cria banco, não executa sincronização e não exige
credenciais.

## Validação

- `dotnet build MyFrame.App/MyFrame.App.csproj --no-restore -v:minimal
  -p:NoWarn=NU1903`: passou, 0 warnings e 0 errors.
- A leitura de banco inexistente retorna quatro fontes em
  `not_initialized`, sem criar o arquivo.
- A stack da F11 é baseada na F10; homologação visual em uma máquina Windows
  continua necessária para conferir layout e acessibilidade.

## Limites

Esta tela não substitui a homologação F1 nem afirma que o inventário Overwolf
está disponível. Ela apenas torna observável o estado persistido que o MCP já
expõe.
