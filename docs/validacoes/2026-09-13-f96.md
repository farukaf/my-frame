# F96 — MCP ativo após atualização do banco

F96 valida o comportamento do leitor MCP durante o cenário de atualização: um
banco SQLite já publicado é aberto por um servidor `stdio` ativo e consultado em
duas chamadas consecutivas de `get_sync_status`.

O teste confirma que:

- o servidor inicia sem executar sincronização de rede;
- o mesmo banco publicado permanece legível enquanto o processo MCP continua ativo;
- a revisão ativa e `parserVersion` (`legacy-parser-1`) permanecem estáveis entre
  as chamadas;
- o processo encerra sem falhar o teste por handles SQLite transitórios no Windows.

Validação executada:

- `dotnet build MyFrame.Mcp.Tests/MyFrame.Mcp.Tests.csproj --no-restore -v:minimal -m:1 -p:UseSharedCompilation=false`;
- teste direcionado `ActiveMcpServerReopensMigratedLegacyDatabase` aprovado;
- suíte MCP: 14/14 testes;
- `git diff --check` aprovado.

A migração/rollback físico do arquivo continua coberta pela F95. O MCP mantém o
leitor somente leitura: migrações são responsabilidade do SyncHost/app antes da
abertura do servidor.
