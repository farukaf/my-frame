# F115 — instalação limpa sem caches legados

F115 inicia o MCP com `MYFRAME_DATA_ROOT` vazio e chama `get_overview` pelo
Inspector. O contrato deve retornar `setupRequired=true` e `SETUP_REQUIRED`,
sem lançar erro ao encontrar um banco SQLite recém-criado.

```powershell
pwsh -File .\scripts\Test-McpCleanInstall.ps1
```

Resultado:

```text
MCP_CLEAN_INSTALL_OK=1
MCP_CLEAN_SETUP_REQUIRED=1
MCP_CLEAN_LEGACY_FILES=0
MCP_CLEAN_SQLITE=1
MCP_CLEAN_EXIT=0
```

O smoke confirmou que só `data.db`/WAL são criados; nenhum cache JSON, settings
legado ou token aparece no root. A regressão `no such table` foi corrigida em
`SqliteSynchronizedDataReader` e coberta por teste Core.
