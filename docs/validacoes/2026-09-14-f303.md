# Validação F303 — gate F10 sem baseline

O gate `Test-F10Evaluation.ps1` continua validando a matriz de três casos, mas
agora imprime `RESULTS_MISSING=<ids>` antes de falhar quando o diretório de
resultados não contém um JSON por caso. Isso diferencia claramente:

- contrato da matriz inválido (falha estrutural);
- baseline ausente (resultado ainda não coletado);
- baseline presente com falha crítica (reprovação da avaliação).

Execução atual:

```text
CASES_OK=3
RESULTS_MISSING=build-unknown-inventory,deimos-mother-token,economy-partial-price
```

O baseline não foi inventado: sua coleta depende de clientes MCP reais, uma
revisão de dados e a homologação F1 do coletor.
