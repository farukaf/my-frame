# F267 — erro sanitizado na ingestão Wiki/Overframe

`MyFrame.Sync --reference-url` agora retorna códigos estáveis em falhas de
rede, timeout ou envelope inválido, sem expor a exceção literal:

- `REFERENCE_NETWORK_UNAVAILABLE`
- `REFERENCE_TIMEOUT`
- `REFERENCE_INVALID_DATA`
- `REFERENCE_FETCH_FAILED`

O gate `Test-ReferenceFetchErrorReadOnly.ps1` verifica estado `failed`, exit
code não zero, ausência de detalhes de transporte e ausência de arquivos no
data root (a criação de uma pasta vazia é permitida pelo runtime).
Conectividade real e autorização das fontes continuam gates externos separados.
