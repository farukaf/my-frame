# F251 — detalhe atribuído de referências no MCP

Foi adicionada a ferramenta read-only `get_reference_section`. Ela recebe a URL,
o `sectionId` e, opcionalmente, a revisão retornados por `search_references` e
retorna um único trecho limitado a 20.000 caracteres, mantendo título, tipo,
URL, revisão, autor/licença e `trustedForFacts`.

Validações:

- busca e detalhe local validado preservam atribuição e conteúdo;
- documento rejeitado continua fora do resultado;
- contrato MCP read-only inclui `get_reference_section`;
- testes direcionados MCP passaram com execução serial (`MaxCpuCount=1`);
- build `MyFrame.Mcp` passou.

A ferramenta não faz rede nem aceita caminho local arbitrário.
