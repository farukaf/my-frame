# Validação F307 — procedência no get_acquisition

`AcquisitionResponse` agora inclui `worldStateParserVersion`, mantendo a
revisão World State que já existia. O campo é preenchido tanto para item
encontrado quanto para item não encontrado, quando há status da fonte, e fica
nulo quando World State não foi inicializado.

Isso permite que o caminho recomendado para perguntas de farm preserve a mesma
distinção de F300: endpoint oficial, fallback comunitário ou fixture genérico.
O contrato continua read-only e não inventa fontes quando a cobertura está
ausente.
