# F62 — revisão ativa no World State

F62 adiciona `activeRevisionId` ao contrato `get_world_state`. A LLM pode
relacionar bounties, ciclos e cobertura ao identificador da revisão publicada,
distinguindo uma resposta baseada em SQLite de uma inferência ou cache antigo.

## Validação

- build MCP sem warnings;
- MCP 13/13 e Core 140/140;
- teste stdio verifica `activeRevisionId` na resposta World State;
- quando a fonte não existe, o campo permanece nulo e o estado continua explícito.
