# F216 — smoke MCP de aquisição com catálogo e World State

## Objetivo

Validar o caminho completo da nova consulta de aquisição com dados semeados:
SQLite → servidor stdio MCP → resposta com componente, relíquia e bounty ativa.

## Validação

O smoke stdio agora publica um item Public Export com componente e fonte de
relíquia, uma bounty Entrati ativa com recompensa do item e chama
`get_acquisition`. A resposta é verificada por conteúdo e continua read-only.

Resultado: 22 testes MCP aprovados. O cenário confirma que a LLM recebe as três
classes de aquisição e que a revisão World State permanece atribuída.
