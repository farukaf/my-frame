# Validação F186 — distribuição 0.0.7 com importação Overwolf

## Publicação

```powershell
pwsh -NoProfile -File .\scripts\Build-Distribution.ps1 `
  -Version 0.0.7 -Configuration Release -RuntimeIdentifier win-x64
```

Resultado: exit code 0. O pacote contém App, MCP e SyncHost atualizados.

## Smoke do executável publicado

O producer Node gerou um capture/marker e o `MyFrame.Sync.exe` de
`artifacts/MyFrame-0.0.7-win-x64` importou o diretório:

```text
state=published
source=overwolf-inventory
discovered=1
imported=1
rejected=0
EquipmentRecords=1
StackableRecords=1
UnknownRecords=0
exit code 0
```

Isso confirma que a opção F185 está presente no artefato distribuível, não
apenas no build Debug.

Os restores emitiram somente `NU1900` por indisponibilidade dos feeds de
auditoria NuGet.
