# Validação F136 — executor World State

`MyFrame.Sync --world-state` publica a fonte oficial `worldstate-pc` usando o
mesmo `SyncHost`/SQLite do App. A saída é JSON sanitizado e o código de saída é
1 quando a fonte não pode ser lida. O runner não ativa o fallback comunitário;
essa escolha mantém a procedência explícita e evita misturar fontes em uma
execução que pretende validar dados oficiais.

Verificações:

```text
dotnet build MyFrame.Sync/MyFrame.Sync.csproj --no-restore -v:minimal -p:NoWarn=NU1900
Build succeeded. 0 Warning(s), 0 Error(s)
--status em diretório temporário: JSON sem rede, três fontes null
```

O smoke real da fonte oficial permanece sujeito à restrição de proxy do
ambiente (`127.0.0.1:9`), já registrada na F134.
