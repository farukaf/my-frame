# Validação F299 — verificador World State no Windows PowerShell

## Alteração

`Test-WorldStateEndpoint.ps1` agora carrega explicitamente
`System.Net.Http` antes de criar `HttpClientHandler`. O script deixa de falhar
por tipo CLR não carregado e consegue reportar o resultado real do transporte,
schema, tamanho e recompensas explícitas.

## Validação

O caminho fixture foi exercitado após a correção e o caminho HTTP foi
reexecutado com timeout de 15 segundos. Se o endpoint estiver bloqueado pelo
ambiente, o resultado agora aparece como `WORLDSTATE_HTTP_OK=0` com erro de
transporte, em vez de um erro de inicialização do script.

Este verificador não publica dados nem altera SQLite.
