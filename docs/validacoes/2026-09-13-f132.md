# Validação F132 — decoder LZMA no fluxo do App

## Objetivo

Garantir que o botão de sincronização do Public Export no App configure o mesmo
decoder LZMA-Alone exigido pelo índice oficial e pelos documentos publicados.

## Alteração

`PublicExportSyncService` agora cria uma única instância de `LzmaAloneDecoder`,
injeta `decoder.Decode` no `PublicExportIndexClient` e reutiliza o decoder no
`PublicExportDocumentClient`. Antes dessa correção, o fluxo de produção usava o
construtor sem decoder e sempre terminava em
`PUBLIC_EXPORT_LZMA_DECODER_NOT_CONFIGURED` antes de publicar qualquer revisão.

## Verificação

```text
dotnet build MyFrame.App/MyFrame.App.csproj --no-restore -v:minimal -p:NoWarn=NU1900
Build succeeded. 0 Warning(s) 0 Error(s)
```

O smoke HTTP da F131 confirmou que a fonte oficial está acessível (HTTP 200,
490 bytes no índice comprimido). A execução contra o serviço real continua
dependente de rede, formato vigente e disponibilidade do documento escolhido;
nenhum dado remoto é incluído nesta validação.
