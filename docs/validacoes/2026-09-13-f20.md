# F20 — status da inbox no MCP

O MCP agora oferece `get_capture_inbox_status`, uma ferramenta somente leitura
que retorna estado (`not_initialized`, `ready` ou `pending`), quantidade de
markers `.ready.json`, timestamp do marker mais recente e o último código de
erro da fonte Overwolf.

O contrato não retorna caminho local nem conteúdo dos arquivos e não publica,
move, apaga ou inicia importação. A suíte de contrato foi atualizada para 11
tools, todas read-only/idempotentes, com schema estrito.
