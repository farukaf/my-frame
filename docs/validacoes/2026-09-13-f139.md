# Validação F139 — sincronização conjunta das fontes oficiais

`MyFrame.Sync --all` executa World State e Public Export em sequência usando o
mesmo SQLite/SyncHost e devolve um resultado por fonte. O processo retorna 0
somente quando ambas publicam; caso contrário retorna 1 com `partial-failure`,
sem esconder qual fonte falhou.

Validação estrutural:

```text
dotnet build MyFrame.Sync/MyFrame.Sync.csproj --no-restore -v:minimal -p:NoWarn=NU1900
Build succeeded. 0 Warning(s), 0 Error(s)
```

O smoke contra as fontes reais continua sujeito à restrição de proxy documentada
em F134/F136; a execução não transforma esse bloqueio em sucesso.
