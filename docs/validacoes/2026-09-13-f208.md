# Validação F208 — descrição atribuída no detalhe MCP

Descrições textuais preservadas no Public Export agora são projetadas no modelo
de catálogo e retornadas por `get_item`. O campo permanece opcional e atribuído à
fonte; a descrição não é tratada como prova de mecânica, posse ou capacidade.

## Evidências

```text
dotnet build MyFrame.Mcp.Tests/MyFrame.Mcp.Tests.csproj --no-restore -v:minimal -m:1 -p:UseSharedCompilation=false
Build succeeded

dotnet vstest MyFrame.Core.Tests/bin/Debug/net10.0/MyFrame.Core.Tests.dll
Passed: 180, Failed: 0

dotnet vstest MyFrame.Mcp.Tests/bin/Debug/net10.0/MyFrame.Mcp.Tests.dll
Passed: 20, Failed: 0
```

Um teste de projeção SQLite confirma a descrição preservada; o contrato MCP
continua read-only e limitado ao texto sincronizado.

## Critérios

- [x] Descrição preservada no modelo de catálogo.
- [x] Descrição disponível no detalhe `get_item`.
- [x] Campo opcional não inventa texto ausente.
- [x] Regressões Core/MCP aprovadas.
