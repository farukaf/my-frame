# Validação F308 — aquisição com procedência World State

Foi adicionado teste MCP que publica catálogo e World State em SQLite e chama
`get_acquisition` para um item encontrado. O teste confirma que a resposta
preserva:

- `state=available` quando catálogo e World State estão publicados, mesmo sem
  bounties observadas;
- `worldStateParserVersion=worldstate-community-1`;
- `worldStateRevisionId` não nulo.

Assim o caminho de aquisição recomendado não perde a distinção de fonte quando
combina catálogo e bounties.
