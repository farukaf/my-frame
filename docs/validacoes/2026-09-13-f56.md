# F56 — metadados de sincronização no MCP

F56 amplia `get_sync_status` com a revisão ativa e as contagens de registros
aceitos e rejeitados por fonte. A resposta continua somente leitura e mantém
`not_initialized` explícito quando não existe revisão local, evitando que uma
lista vazia seja interpretada como fonte sincronizada.

## Validação

- build do MCP sem warnings;
- suíte MCP completa, incluindo a revisão World State publicada no fixture;
- suíte Core completa;
- tabela e descrição do MCP atualizadas.
