# F113 — caches de mercado no SQLite

F113 adiciona `SqliteMarketStore`, que implementa os contratos de cotações,
estado de conta/ordens e índice de itens. App e MCP agora compartilham o mesmo
`data.db` para esses dados.

Na primeira abertura, os arquivos legados `market-quotes.json`,
`market-data.dat` e `market-items.dat` são importados somente quando a tabela
SQLite correspondente está vazia. Eles não são removidos, permitindo rollback
manual. Novas escritas vão exclusivamente para SQLite.

Evidências:

```text
Core build: 0 warnings, 0 errors
MCP build: 0 warnings, 0 errors
App build: 0 warnings, 0 errors
SqliteMarketStoreTests: 2 passed, 0 failed
MCP suite: 18 passed, 0 failed
```

O escopo desta fase cobre caches/estado de mercado. Settings e token continuam
com seus formatos próprios por razões de compatibilidade e segurança; o token
nunca é importado para o banco.
