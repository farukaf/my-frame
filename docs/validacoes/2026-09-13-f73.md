# F73 — limites e filtros World State no stdio

F73 adiciona regressões no cliente MCP real: um sindicato sem bounties retorna
lista vazia sem vazar a bounty de outra facção, e `limit=0` retorna erro de
argumento. Ciclos e estado da fonte continuam disponíveis no resultado filtrado.

## Validação

- build MCP sem warnings;
- MCP 13/13;
- filtro `Ostrons` não retorna a bounty `deimos-f33` do fixture `Entrati`;
- limite fora de 1–200 é rejeitado pelo protocolo.
