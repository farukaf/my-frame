# F223 — serializer testável de diagnósticos sanitizados

## Implementação

O formato do diagnóstico foi extraído para `SyncDiagnosticsSerializer` no Core.
A UI apenas converte as linhas de status para DTOs sanitizados e copia o JSON;
isso permite verificar o contrato sem depender de clipboard ou janela Windows.

## Validação

- Core: 181 testes aprovados, incluindo rejeição de payload, token e caminho local;
- App: build `net10.0-windows10.0.19041.0/win-x64` aprovado;
- avisos NU1900 permanecem apenas por indisponibilidade do proxy/NuGet.
