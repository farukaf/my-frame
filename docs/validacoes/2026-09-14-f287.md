# F287 — heartbeat encerra explicitamente ao parar o coletor

Ao clicar em Parar, a extensão agora grava um heartbeat com state=stopped depois
de limpar listeners e memória. Como o probe só considera state=started como
heartbeat fresco, o MCP deixa de sinalizar uma extensão ativa após uma parada
intencional. O heartbeat também continua sem payload privado.

Validação:

    Node collector/UI/transport: 15/15
