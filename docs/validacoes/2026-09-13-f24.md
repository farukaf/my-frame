# F24 — histórico de sincronização no MCP

O MCP agora oferece `get_sync_history`, usando a mesma tabela `sync_runs` da
UI. A ferramenta é somente leitura, idempotente e aceita `limit` entre 1 e 100
e um `sourceId` opcional.

Cada registro retorna apenas identificador de tentativa, fonte, estado,
horários, contagens e código de erro sanitizado. Payloads, caminhos, tokens e
ações de sincronização ficam fora do contrato.

Validação: schema estrito atualizado para 12 tools; build MCP sem warnings e
teste stdio real deve ser executado após recompilar o assembly de testes.
