# F210 — probe operacional do Public Export

## Objetivo

Adicionar um comando de diagnóstico que valide a disponibilidade do índice e dos
documentos JSON do Public Export sem abrir o banco de dados, publicar revisão ou
alterar o estado local.

## Implementação

`MyFrame.Sync --public-export-probe` baixa o índice oficial, filtra os documentos
JSON, aplica os mesmos limites e parser usados pelo sync e retorna JSON com:

- estado `reachable` ou `unreachable`;
- quantidade de entradas do índice, documentos de catálogo e registros;
- versão do parser;
- caminho e `revisionTag` de cada documento;
- `errorCode` sem stack trace quando a fonte não está disponível.

O probe não cria `SyncDatabase` e, portanto, não escreve SQLite nem altera status.
Ele é apropriado para a página de status, diagnóstico de instalação e homologação
antes de habilitar um sync real.

## Validação

```powershell
dotnet build MyFrame.Sync/MyFrame.Sync.csproj --no-restore -v:minimal -m:1 -p:UseSharedCompilation=false
dotnet run --project MyFrame.Sync/MyFrame.Sync.csproj --no-build -- --public-export-probe
```

Build concluído com sucesso (apenas os avisos NU1900 já conhecidos). No ambiente
isolado, a execução retornou `state=unreachable` e o erro de conexão do proxy
`127.0.0.1:9`; isso confirma o caminho de falha sem simular dados online.

Quando a rede estiver disponível, o mesmo comando deve retornar `state=reachable`
e registrar os documentos reais antes da homologação F1/F10.
