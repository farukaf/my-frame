# F88 — detecção explícita de Mother Token

F88 adiciona uma fixture comunitária com `rewardPoolDrops` contendo `Mother
Token`. O verificador detecta a recompensa somente porque ela está explícita no
payload; a fixture oficial F87 continua retornando zero. Isso evita confundir
pool de recompensa, nome de bounty ou cobertura ausente com uma quantidade farmável.

Execução:

```text
WORLDSTATE_HTTP_OK=SKIPPED
WORLDSTATE_TRANSPORT=fixture
WORLDSTATE_SCHEMA=community
WORLDSTATE_MISSIONS=1
WORLDSTATE_EXPLICIT_REWARDS=1
WORLDSTATE_EXPLICIT_MOTHER_TOKENS=1
```
