# Validação F154 — sincronização conjunta local

`MyFrame.Sync --all-local --public-export-directory <dir> --world-state-file <arquivo.json>`
executa as duas fontes locais em sequência sobre o mesmo SyncHost. O resultado
é `published` somente quando ambas publicam; caso contrário retorna
`partial-failure` e preserva a revisão ativa da fonte que passou.

Exemplo:

```powershell
dotnet run --project .\MyFrame.Sync -- --all-local `
  --public-export-directory .\public-export `
  --world-state-file .\worldState.json `
  --data-root .\artifacts\sync-root
```

O JSON de saída contém estado, contagem, revisão, parser version e erro de cada
fonte, permitindo à página de status/MCP explicar uma falha parcial sem tratar o
catálogo ou World State como conjunto vazio válido.
