# F22 — restore SQLite

`SyncDatabase.RestoreAsync` restaura um backup para o banco ativo usando o
backup nativo do SQLite em um arquivo temporário no mesmo diretório. Só depois
de fechar as conexões e concluir a cópia o arquivo temporário substitui o banco;
em falha, o temporário é removido e o banco ativo não é alterado.

Regras de segurança:

- origem precisa existir, não ser reparse point e ser diferente do destino;
- o escritor SQLite é serializado pelo mesmo gate das publicações;
- sidecars WAL/SHM antigos são removidos após a substituição;
- não há leitura de payload, rede ou dependência AlecaFrame.

Validação: teste publica uma revisão, cria backup, altera o banco ativo,
restaura e confirma a revisão original após reabrir o status.
