# F63 — gate MCP read-only em data root limpo

O gate de distribuição foi executado contra o executável MCP compilado:

```text
MCP_READONLY_OK=1
MCP_EXIT=0
```

Comando:

```powershell
$server = Resolve-Path .\MyFrame.Mcp\bin\Debug\net10.0\win-x64\MyFrame.Mcp.exe
& .\scripts\Test-McpReadOnly.ps1 -ServerPath $server
```

O processo recebeu EOF no stdin, terminou com código zero, não escreveu bytes
no stdout e não criou arquivos no data root temporário. Isso não substitui a
validação de rede/produção nem a homologação real do coletor Overwolf.
