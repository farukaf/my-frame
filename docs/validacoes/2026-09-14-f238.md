# F238 — smoke Mother Token e descoberta de skills

## Smoke real

Claude e Codex, usando o MCP 0.0.15, consultaram capacidades, status, captura,
overview, World State, aquisição, cobertura e loadout antes de responder sobre
Mother Tokens. Ambos responderam `unverified`, não inventaram build/tokens por
hora/posse e explicitaram World State/captura ausentes.

O smoke também revelou que `Skill(warframe-farm)` não é descoberta
automaticamente pelo Claude Code quando a skill existe apenas em `skills/` do
repositório.

## Correção

- `CLAUDE.md` adiciona roteamento explícito para as skills versionadas;
- `Install-MyFrameSkills.ps1` oferece instalação controlada para Claude/Codex,
  com `-WhatIf`, `-Force` e destino de teste;
- cópia para destino temporário foi executada e instalou as quatro skills;
- a instalação global não é executada automaticamente.
