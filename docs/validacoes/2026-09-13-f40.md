# F40 — preflight sem mutação de schema futuro

F40 move a verificação de `schema_migrations` para antes do DDL de
inicialização. Se o banco já registrar uma versão maior que a suportada, a
abertura falha com `SYNC_SCHEMA_NEWER` sem criar tabelas auxiliares nem tocar
nas tabelas do banco incompatível.

## Validação

- banco sintético com versão 99 e sentinela existente;
- `InitializeAsync` rejeita o arquivo;
- a sentinela permanece e `source_revisions` não é criado;
- Core: 134 testes aprovados.
