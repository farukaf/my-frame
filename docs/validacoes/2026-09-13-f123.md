# Validação F123 — readiness não-mutante dos clientes MCP

O probe `scripts/Test-McpClientReadiness.ps1` consulta apenas `mcp get my-frame`
nos CLIs instalados, aplica timeout e nunca executa `mcp add` nem altera arquivos
de configuração.

Resultado observado em 13/09/2026:

```text
MCP_CLIENT_READINESS_PROBE_OK=1
MCP_CODEX_STATE=ok
MCP_CLAUDE_STATE=not-configured
MCP_CLIENT_READINESS_MUTATIONS=0
```

O smoke real do Claude continua pendente até o usuário cadastrar o servidor. A
ausência é registrada explicitamente; não é tratada como falha do MCP nem como
smoke aprovado.

Também foi tentado o smoke real do Codex configurado. A execução foi interrompida
antes de chamar `get_overview` porque isso poderia enviar inventário local ao
serviço remoto do Codex; a autorização explícita de egress ainda não foi dada.
Portanto `MCP_CODEX_STATE=ok` comprova somente o cadastro/configuração, não uma
resposta real do cliente.
