# F60 — substituição de cobertura entre revisões

F60 evita que a cobertura de uma revisão antiga contamine a revisão atual. A
publicação World State remove a cobertura anterior da fonte dentro da mesma
transação e grava todos os campos observados na nova revisão. Assim, uma fonte
que deixou de entregar Mother Token volta corretamente para `NotObserved`.

## Validação

- build Core sem warnings;
- Core 139/139;
- regressão publica duas revisões, `Known` e `NotObserved`, e verifica o estado final;
- publicação continua atômica.
