# F45 — bounties World State no MCP

F45 adiciona a ferramenta somente leitura `get_bounties`. Ela lê somente a
revisão World State ativa, aplica a validade temporal e retorna bounties com
jobs, estágios e recompensas atribuídas.

Quando o banco não tem World State, a resposta estruturada permanece vazia;
isso não é convertido em prova de que não existem bounties. O status de
sincronização continua sendo a fonte para distinguir ausência de dados de uma
lista legitimamente vazia.

## Validação

- descoberta estática confirma 17 ferramentas somente leitura;
- teste stdio chama `get_bounties` em data root sem World State e recebe
  conteúdo estruturado sem erro;
- Core: 137 e MCP: 12 testes aprovados.
