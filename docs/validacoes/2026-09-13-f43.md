# F43 — resolução do índice Public Export

F43 adiciona `SyncHost.RunPublicExportLatestOnceAsync`, que busca o índice,
resolve uma entrada pelo caminho relativo exato e só então baixa/publica o
documento. Entradas ausentes falham com `PUBLIC_EXPORT_ENTRY_NOT_FOUND` e não
criam revisão ativa.

O caminho continua sendo escolhido pelo orquestrador (por exemplo, o arquivo
de armas ou warframes), evitando que o host aceite redirecionamentos de
arquivo não autorizados.

## Validação

- fixture HTTP roteia índice e documento em endpoints distintos;
- host resolve `ExportWeapons_en.json!fixture` e publica `Latest`;
- Core: 137 testes aprovados.
