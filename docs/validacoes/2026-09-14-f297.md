# Validação F297 — redirect seguro no World State

## Alteração

O `WorldStateClient` compara a URL efetiva da resposta com o endpoint
configurado antes de interpretar ou publicar o payload. Redirect que troca o
esquema ou o host falha com `WORLDSTATE_REDIRECT_UNSUPPORTED`; redirects dentro
do mesmo host HTTPS continuam compatíveis com `HttpClient`.

O limite existente de 32 MiB, validação UTF-8, parser e política de fallback
comunitário permanecem inalterados.

## Testes

- `ClientRejectsRedirectToDifferentWorldStateHost`: aprovado.
- suíte `MyFrame.Core.Tests`: executada no PR.

## Resultado

O pipeline não publica World State vindo de uma origem diferente daquela
configurada, reduzindo risco de dados inesperados para consultas de bounties e
Mother Tokens. A homologação com o endpoint oficial ainda depende de rede e
ambiente autorizados.
