# F217 — distribuição 0.0.14 com aquisição MCP

## Objetivo

Verificar que o contrato de aquisição chega ao artefato Windows distribuível,
não apenas à compilação de testes.

## Validação

```powershell
./scripts/Build-Distribution.ps1 -Version 0.0.14
./scripts/Test-McpFailureReadOnly.ps1 -ServerPath artifacts/MyFrame-0.0.14-win-x64/MyFrame.Mcp.exe
$env:MYFRAME_MCP_TEST_SERVER = (Resolve-Path artifacts/MyFrame-0.0.14-win-x64/MyFrame.Mcp.exe).Path
dotnet test MyFrame.Mcp.Tests/MyFrame.Mcp.Tests.csproj --no-build --filter FullyQualifiedName~RealStdioServerListsAndCallsStructuredCapabilities
```

O publish produziu `MyFrame.App.exe`, `MyFrame.Mcp.exe` e `MyFrame.Sync.exe`.
O teste do executável distribuído aprovou o smoke stdio com `get_acquisition`.
O gate de falha confirmou 0 sockets, 2 respostas JSON-RPC, erro sanitizado e
nenhuma escrita na raiz limpa. Os avisos NU1900/XAML são os já conhecidos.
