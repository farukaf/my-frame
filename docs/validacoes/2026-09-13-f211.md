# F211 — gate read-only do probe Public Export

## Objetivo

Garantir por execução que `--public-export-probe` não cria a raiz de dados nem
modifica arquivos existentes, independentemente de a fonte estar acessível.

## Validação

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Test-PublicExportProbeReadOnly.ps1
```

O script usa uma raiz temporária ausente, executa o probe com `--data-root`,
interpreta o JSON retornado e exige que a raiz continue ausente. Em uma raiz já
existente, compara caminho, tamanho e timestamp de todos os arquivos. O resultado
esperado é `PUBLIC_EXPORT_PROBE_READONLY=1`; `PROBE_STATE` pode ser `reachable` ou
`unreachable` conforme a rede.
