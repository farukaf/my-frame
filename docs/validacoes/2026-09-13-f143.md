# Validação F143 — cobertura de fontes no MCP

Foi adicionada a ferramenta read-only `get_source_coverage`, limitada às fontes
`public-export`, `worldstate-pc` e `overwolf-inventory`. Ela retorna apenas
`sourceId`, caminho do campo e estado (`Known`, `NotObserved`, etc.), sem payload
bruto, token ou caminho local.

Validação:

```text
MyFrame.Mcp.Tests: 18/18
MyFrame.App build: 0 erros, 0 warnings
Ferramentas MCP descobertas: 20
```

O contrato mantém `NotObserved` explícito para impedir que a LLM trate campo
ausente do catálogo como valor conhecido.
