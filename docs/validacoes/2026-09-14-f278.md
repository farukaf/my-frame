# F278 — distribuição 0.0.25 e smoke MCP nos clientes

## Objetivo

Validar que o contrato F277 chegou ao executável realmente usado pelo Codex e
Claude, e não apenas à DLL de testes.

## Execução

- pacote gerado em `artifacts/MyFrame-0.0.25-win-x64`;
- registros globais `my-frame` do Codex e Claude apontados para o `MyFrame.Mcp.exe`
  0.0.25;
- ambos os clientes autorizados a chamar `get_source_coverage` uma vez, em modo
  somente leitura, com `sourceId=public-export`.

## Resultado observado

Codex e Claude receberam a mesma resposta estruturada:

```json
{"items":[],"state":"not_initialized","activeRevisionId":null,"parserVersion":null}
```

Os campos `localizedNames` e `technicalMetadata` foram corretamente tratados
como ausentes enquanto não há uma revisão Public Export publicada; nenhum cliente
inventou cobertura `Known`. Claude registrou zero negações de permissão.

Essa ausência é esperada no ambiente atual: o host externo do Public Export segue
indisponível, portanto a validação confirma o contrato e a procedência, não a
cobertura de dados reais.
