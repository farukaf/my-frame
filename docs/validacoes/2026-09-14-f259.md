# F259 — histórico de revisões do inventário no MCP

Foi adicionada a ferramenta read-only `get_inventory_history`. Ela expõe apenas
metadados sanitizados das revisões SQLite: `revisionId`, hash, sequência,
completude, `captureMode` (`snapshot`/`delta`) e horário de recebimento.

Uma fonte sem revisões retorna `not_initialized`; o contrato não transforma uma
delta em inventário completo.

Validação: build MCP aprovado; teste de inbox sem dados e teste de contrato
read-only aprovados.
