# F105 — configuração dos clientes MCP

F105 valida o onboarding local dos clientes sem alterar arquivos de configuração
do usuário nem executar uma chamada de modelo.

Resultado observado:

- Codex CLI instalado e `codex mcp get my-frame` confirmou o servidor habilitado;
- o comando Codex aponta para `MyFrame.Mcp.exe` da árvore de desenvolvimento;
- Claude CLI instalado, mas `my-frame` ainda não cadastrado;
- os dois comandos gerados pelo App foram validados quanto à forma e ao caminho;
- `MCP_CLIENT_CONFIG_OK=1`.

O cadastro Claude permanece uma ação explícita do usuário, documentada na UI; não
foi executado automaticamente para evitar mutação de configuração fora do repo.
