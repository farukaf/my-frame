# F81 — fallback controlado do World State

F81 habilita o app a tentar o endpoint oficial primeiro e usar WarframeStat.us
somente quando ocorre falha de transporte, erro HTTP ou timeout. Falhas de
parsing/schema não acionam fallback e cancelamento do usuário nunca é mascarado.
O `parserVersion` permanece `worldstate-community-1` quando o fallback é usado,
permitindo rastrear a procedência no status MCP.

Validação executada:

- fixture que falha na primeira requisição e responde na segunda;
- fallback retorna parser comunitário identificável;
- Core: 146/146 testes;
- MCP: 13/13 testes;
- build sem warnings nem erros.
