# Validação F134 — executor local de sincronização Public Export

## Objetivo

Disponibilizar uma fronteira executável para sincronização fora da UI, útil para
automação local, diagnóstico e futura tarefa agendada. O comando grava no mesmo
SQLite usado pelo App e não depende de AlecaFrame.

## Uso

```powershell
dotnet run --project MyFrame.Sync -- --public-export
dotnet run --project MyFrame.Sync -- --public-export --data-root C:\caminho\MyFrame
dotnet run --project MyFrame.Sync -- --status --data-root C:\caminho\MyFrame
dotnet run --project MyFrame.Sync -- --all
```

O stdout é um JSON sanitizado com estado, contagem, revisão, parser, arquivo e
tag da fonte. Falhas retornam código diferente de zero e não substituem a
revisão ativa; o `SyncHost` registra o erro no status SQLite.
`--status` não acessa a rede e retorna o estado das fontes Public Export, World
State e inventário Overwolf.

## Verificação
