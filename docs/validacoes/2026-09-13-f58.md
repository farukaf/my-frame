# F58 — cobertura explícita de Mother Token

F58 melhora a qualidade da resposta para farm em Deimos sem criar uma tabela
inventada: o parser marca `motherTokens` como `Known` somente quando alguma
recompensa do World State contém explicitamente o texto `Mother Token`. Sem esse
texto, a cobertura continua `NotObserved`, e a LLM deve informar que a fonte
não permite concluir a quantidade.

## Validação

- `dotnet test MyFrame.Core.Tests/MyFrame.Core.Tests.csproj --no-build -v:minimal`;
- caso positivo com recompensa `Mother Token`;
- regressão existente continua garantindo `NotObserved` para um World State que só contém Endo;
- build e `git diff --check` limpos.
