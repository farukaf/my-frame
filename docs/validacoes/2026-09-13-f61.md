# F61 — substituição de cobertura do inventário

F61 aplica a mesma regra de consistência à fonte `overwolf-inventory`: a
cobertura anterior é removida antes de gravar a nova projeção, na transação da
revisão. Campos que deixam de ser observados não permanecem falsamente
`Known`.

## Validação

- build Core sem warnings;
- Core 140/140;
- regressão publica duas revisões com estados diferentes e verifica o estado final;
- dados de equipamento e upgrades continuam idempotentes.
