# F248 — ingestão atribuída de referências Wiki/Overframe

O SyncHost agora aceita `--reference-url <https-url>` para buscar uma referência
permitida, validar o envelope, limitar o corpo a 16 MiB e armazená-lo por hash na
pasta local de referências. O MCP continua somente leitura e não faz rede.

Validações:

- `ReferenceSyncRunner` buscou uma resposta HTTP controlada, preservou URL,
  revisão, autoria/licença e foi idempotente;
- host fora de `wiki.warframe.com`/`overframe.gg` foi rejeitado com
  `REFERENCE_URL_UNSUPPORTED`;
- `MyFrame.Sync --reference-url https://example.com/x` retornou estado `failed`
  e código 1, sem aceitar a fonte.

O conteúdo importado permanece não confiável para fatos do jogo; a integração
automática com endpoints reais depende de conectividade e dos termos de cada fonte.
