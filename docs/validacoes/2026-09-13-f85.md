# F85 — fluxo oficial até SQLite

F85 testa o caminho integrado da fonte oficial: payload HTTP no schema da DE é
decodificado pelo `WorldStateClient`, publicado pelo `SyncHost` e lido do SQLite
com `parser_version=worldstate-official-1`. Como o fixture oficial fornece apenas
o identificador do pool de recompensa, a revisão persiste a bounty sem inventar
itens ou Mother Tokens.

Validação executada:

- publicação e leitura da bounty oficial no SQLite;
- procedência oficial preservada no status;
- Core: 148/148;
- MCP: 13/13;
- App Windows build sem warnings ou erros.
