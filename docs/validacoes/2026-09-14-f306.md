# Validação F306 — teste ponta a ponta da procedência World State

Foi adicionado um teste MCP que publica uma revisão World State em SQLite com
`parserVersion=worldstate-official-1` e consulta `get_world_state`/`get_bounties`
pela `PlatformStatusService`.

O teste confirma que:

- `state=available` é retornado somente após publicação;
- `activeRevisionId` é o mesmo nas duas consultas;
- `parserVersion` é preservado;
- cobertura `motherTokens=NotObserved` não vira recompensa inventada.

Esse teste cobre o caminho SQLite→MCP; não substitui a captura Overwolf nem o
acesso real ao endpoint oficial.
