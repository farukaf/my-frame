# F231 — contrato MCP do status de runtime do coletor

## Objetivo

Garantir que a nova resposta de `get_capture_inbox_status` permaneça útil para
a LLM sem vazar o diretório ou o payload privado.

## Validação

- teste com raiz inexistente retorna `not_initialized`;
- heartbeat é explicitamente `false`/nulo quando ausente;
- resposta não contém a raiz local de dados;
- suíte MCP: 23 testes aprovados;
- documentação de `docs/MCP.md` atualizada com os campos operacionais.
