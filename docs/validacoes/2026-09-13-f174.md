# Validação F174 — smoke real do MCP Inspector e dependência DPAPI

O primeiro smoke real descobriu que o executável MCP não carregava
`System.Security.Cryptography.ProtectedData` ao chamar
`get_market_credential_status`. A dependência foi adicionada diretamente ao
projeto MCP para garantir que o assembly seja distribuído junto do servidor.

Após restore/build, o Inspector real foi executado com sucesso:

```text
MCP_INSPECTOR_CALLS_OK=1
MCP_INSPECTOR_CALLS_COUNT=4
MCP_INSPECTOR_CALLS_STRUCTURED=4
```

As chamadas foram capabilities, sync status, status de credencial e World
State. Nenhum token foi retornado.
