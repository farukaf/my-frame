# Validação F169 — diagnóstico seguro do World State

O runner e o `SyncHost` agora classificam falhas de transporte do World State
como `WORLDSTATE_NETWORK_UNAVAILABLE`, mantendo códigos HTTP oficiais e erros
de payload separados. A falha não vira uma lista vazia de bounties.

## Evidência

```text
SharedWorldStateRunnerClassifiesTransportFailureWithoutLeakingDetails: Passed
```

O teste usa um handler local que lança uma exceção de transporte; a mensagem
original não aparece no resultado.
