# F59 — cobertura World State persistida no MCP

F59 persiste os campos de cobertura produzidos pelo parser na fonte
`worldstate-pc` e adiciona `coverage` à resposta de `get_world_state`. Assim a
LLM recebe a distinção entre `Known` e `NotObserved` junto com as bounties, em
vez de precisar inferir a partir de uma lista vazia.

- Core 138/138 e MCP 13/13;
- teste stdio verifica a presença de `motherTokens` na resposta;
- leitura continua somente leitura e não cria banco quando a fonte não existe.
