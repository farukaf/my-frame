# Validação F148 — preflight reproduzível do coletor Overwolf

O script `scripts/Test-OverwolfCollectorPreflight.ps1` reconstrói o pacote,
valida manifest/ícone e executa o gate read-only F147. O código final continua
falhando quando a extensão não foi carregada ou não existe captura, sem ocultar
essa dependência externa.

Execução local:

```text
PACKAGE_BUILD=1
Collector package valid: ...\artifacts\collector-overwolf
PACKAGE_VALID=1
OVERWOLF_PROCESS=1
WARFRAME_PROCESS=1
COLLECTOR_MANIFEST=1
COLLECTOR_EXTENSION_LOGGED=0
CAPTURE_MARKERS=0
OVERWOLF_COLLECTOR_READY=0
OVERWOLF_PREFLIGHT_READY=0
exit code: 1
```

O pacote local está válido. A homologação F1 permanece pendente de carregar a
extensão unpacked no Overwolf e produzir uma captura real.
