# Validação F162 — hosts oficiais separados do Public Export

O índice inglês do Public Export continua em `origin.warframe.com`, mas os
documentos referenciados pelo índice são resolvidos no host de conteúdo
`content.warframe.com`. O cliente estava usando a origem também para os
documentos; isso reproduzia o `403` observado na validação de rede.

## Alteração

`PublicExportIndexClient` mantém a URL do índice em `origin`, enquanto
`PublicExportDocumentClient.DefaultBaseUrl` passa a usar a base oficial de
conteúdo. A URL explícita fornecida por testes/operadores continua tendo
precedência.

## Evidência

```text
PublicExportUsesSeparateOfficialIndexAndDocumentHosts: Passed
Total: 1, Failed: 0
```

Os avisos NU1900 são apenas falhas de consulta ao feed de vulnerabilidades no
ambiente local; não alteram o resultado do teste.
