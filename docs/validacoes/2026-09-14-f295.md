# Validação F295 — media types JSON estruturados

## Alteração

A validação de resposta do `ReferenceSyncRunner` aceita `application/json` e
media types estruturados `application/*+json` concretos, por exemplo
`application/ld+json`. O wildcard literal não é tratado como media type; a
regra verifica o prefixo `application/` e o sufixo `+json`.

Respostas declaradas como HTML ou outro tipo continuam rejeitadas, assim como
redirects para fora dos hosts HTTPS autorizados.
