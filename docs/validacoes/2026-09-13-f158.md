# Validação F158 — skill de pesquisa atribuída

Foi criada `skills/warframe-research/SKILL.md`, orientando a LLM a usar
`search_references`, preservar URL/revisão/autoria/licença e separar referências
comunitárias (`trustedForFacts=false`) dos fatos sincronizados.

`warframe-builds` também foi alinhada para usar a ferramenta nova quando buscar
slots, ranks ou mods de uma build comunitária. A skill não autoriza scraping nem
rede como fallback.

A validação automática `quick_validate.py` não foi executada porque o ambiente
não possui o módulo Python `yaml` (`ModuleNotFoundError`); frontmatter, nome,
referências e ausência de placeholders foram revisados manualmente.
