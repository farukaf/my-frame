# F69 — instalação nova sem caminho AlecaFrame

F69 remove o default que criava uma dependência aparente do AlecaFrame em novas
instalações. A migração preserva uma preferência legada somente quando ela já
existe; caso contrário, `AlecaFrameDirectory` fica vazio e o SQLite/coletor é o
caminho primário. A seleção manual do diretório continua disponível como
importação opcional.

## Validação

- build MyFrame.App sem erros;
- configurações existentes continuam preservadas;
- configuração nova não cria nem aponta para `%LOCALAPPDATA%\\AlecaFrame`;
- F68 mantém o fallback legado quando uma projeção SQLite utilizável não existe.
