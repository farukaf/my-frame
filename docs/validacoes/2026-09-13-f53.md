# F53 — limite de resposta do World State

F53 aplica limite obrigatório de 1 a 200 bounties em `get_world_state`,
evitando resposta sem orçamento quando a fonte tiver muitas atividades. Ciclos
continuam completos e o estado da fonte permanece no envelope.

## Validação

- schema MCP expõe `limit` com default 100;
- teste stdio chama a ferramenta com limite explícito;
- limite fora do intervalo é rejeitado pelo contrato de argumentos.
