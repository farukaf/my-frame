# Validação F317 — checklist F6 reconciliado

O item de planejamento “resolver autenticação WFM independente” estava
marcado como pendente apesar de já haver evidência de implementação:

- armazenamento protegido por DPAPI independente do AlecaFrame (F116);
- serviço local de status, validação, gravação e revogação (F117);
- UX de salvar/status/revogar sem expor o token (F118);
- estado seguro exposto no MCP e smoke correspondente (F168/F173).

O checklist agora marca F6 como concluído. Isso não declara credencial
configurada para uma conta específica: o estado continua opcional e as
consultas públicas do mercado permanecem disponíveis sem token.
