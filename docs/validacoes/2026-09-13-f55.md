# F55 — inicialização sem dependência de AlecaFrame

F55 ajusta o caminho padrão da aplicação para priorizar a projeção SQLite
sincronizada pelo coletor. Se houver inventário e catálogo sincronizados, a tela
inicializa e atualiza o dashboard mesmo sem a pasta AlecaFrame configurada. A
importação legada permanece disponível apenas como fallback opcional quando não
há dados sincronizados.

## Validação

- `dotnet build MyFrame.App/MyFrame.App.csproj --no-restore -v:minimal -m:1 -p:UseSharedCompilation=false` — 0 warnings, 0 errors;
- `dotnet test MyFrame.Core.Tests/MyFrame.Core.Tests.csproj --no-build -v:minimal` — 137/137;
- teste `UsesSynchronizedDataWhenAlecaSettingsAreMissing` cobre a projeção sem configuração AlecaFrame;
- mensagens do dashboard e do serviço não classificam mais a ausência de dados SQLite como falha específica do AlecaFrame.
