# F27 — smoke de instalação limpa

O artefato `0.0.6-win-x64` foi executado com `MYFRAME_DATA_ROOT` apontando
para um diretório temporário sem settings, AlecaFrame ou banco legado.

Resultados:

- `MyFrame.App.exe`: permaneceu ativo por 8 segundos e foi encerrado pelo PID
  criado pelo smoke; não houve `startup-error.log` novo;
- `MyFrame.Mcp.exe`: recebeu stdin vazio, encerrou com `EXIT=0` em 5.533 ms;
- o diretório de dados temporário não recebeu payload ou arquivo inesperado.

Esta evidência cobre inicialização/encerramento básicos do pacote. Não substitui
instalação Windows totalmente limpa nem homologação real Overwolf/Warframe.
