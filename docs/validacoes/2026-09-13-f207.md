# Validação F207 — cobertura de fonte visível na página de status

A página de sincronização do App agora mostra, por fonte, um resumo sanitizado
dos campos observados (`Known`, `NotObserved`, etc.). O resumo é derivado do
mesmo SQLite e não inclui payload bruto, IDs pessoais ou segredos.

## Evidências

```text
dotnet build MyFrame.App/MyFrame.App.csproj --no-restore \
  -f net10.0-windows10.0.19041.0 -r win-x64 -v:minimal
Build succeeded
```

Fontes sem revisão exibem `Coverage: —`; fontes publicadas exibem os campos
ordenados de forma determinística, permitindo identificar por que uma resposta
é parcial antes de usar o catálogo/inventário.

## Critérios

- [x] Cobertura visível por fonte na UI.
- [x] Estado `NotObserved` não é convertido em zero.
- [x] Sem payload bruto ou segredo na tela.
- [x] Build App Windows aprovado.
