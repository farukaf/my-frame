# Validação F204 — runbook Overwolf executável diretamente

Os scripts do gate F1 não dependem mais de `$PSScriptRoot` em valores padrão do
bloco `param`. Os caminhos padrão são resolvidos depois da inicialização do
script, evitando falha de `Join-Path` quando o PowerShell avalia parâmetros antes
de definir a variável automática.

## Evidências

```text
scripts/Test-OverwolfCollectorReadiness.ps1
OVERWOLF_PROCESS=1
WARFRAME_PROCESS=1
COLLECTOR_MANIFEST=1
COLLECTOR_EXTENSION_LOGGED=0
COLLECTOR_HEARTBEAT=0
CAPTURE_MARKERS=0
OVERWOLF_COLLECTOR_READY=0

scripts/Test-CollectorPackage.ps1
Collector package valid: MyFrame.Collector.Overwolf

scripts/Start-OverwolfCollectorDev.ps1
Collector package valid: artifacts/collector-overwolf
OVERWOLF_ALREADY_RUNNING=1
NEXT_STEP=Overwolf Settings > About > Development Options > Load unpacked extension
```

O runbook agora executa corretamente e o gate continua `0` por motivo real: a
extensão ainda não deixou heartbeat/marker observável. Isso não é contado como
captura aprovada.

- [x] Caminhos padrão funcionam em chamada direta.

- [x] Próximo passo manual continua explícito.
- [ ] Extensão carregada e captura real GEP ainda pendentes.
