# F42 — publicação integrada do World State

F42 adiciona `SyncHost.RunWorldStateOnceAsync`, conectando o cliente World
State à publicação SQLite. O fluxo busca a fonte, valida o JSON e publica a
revisão com bounties, ciclos e recompensas na mesma operação; falhas são
registradas como tentativa `worldstate-pc`.

## Validação

- `HttpClient` fixture fornece um World State mínimo;
- o host publica a revisão;
- consulta posterior retorna a bounty Entrati ativa;
- Core: 136 testes aprovados.
