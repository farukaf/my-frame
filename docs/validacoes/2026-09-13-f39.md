# F39 — manutenção do SyncHost

F39 adiciona `SyncHost.RunMaintenanceAsync`, uma fronteira explícita para
executar a retenção SQLite enquanto o host está ativo. A operação reutiliza o
escritor único do `SyncDatabase`, atualiza o instante da última execução e
mantém consultas MCP independentes do host.

## Validação

- três publicações são feitas pelo mesmo banco;
- manutenção com limite dois remove uma revisão retida;
- o host fica em estado `Running`, registra `LastRunAt` e a revisão ativa
  permanece disponível;
- Core: 134 testes aprovados.
