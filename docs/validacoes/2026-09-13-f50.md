# F50 — paridade documental das ferramentas MCP

F50 atualiza `docs/MCP.md` para refletir as 17 ferramentas atualmente
registradas em `MyFrameTools`, incluindo capacidades, sincronização, inbox,
inventário rico, loadouts, mods e bounties.

A documentação também distingue respostas de estado sem paginação das listas
analíticas com `snapshotId` e cursores assinados. Nenhuma ferramenta de escrita
é adicionada.

## Validação

- a tabela contém os nomes das 17 ferramentas esperadas pelo teste de registro;
- anotações de segurança continuam somente leitura/idempotentes;
- descrição de paginação permanece compatível com os contratos atuais.
