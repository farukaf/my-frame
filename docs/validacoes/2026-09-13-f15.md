# F15 — comando operacional de importação

## Entrega

`MyFrame.Collector.Probe` agora possui dois modos:

```powershell
# somente validar, sem escrever
MyFrame.Collector.Probe.exe --marker C:\captura\<event>.ready.json

# validar e publicar no SQLite, com consentimento explícito
MyFrame.Collector.Probe.exe --import --marker C:\captura\<event>.ready.json --database C:\dados\data.db --allow-raw
```

O modo `--marker` continua sem escrita. O modo `--import` exige exatamente a
flag `--allow-raw`, publica via `CollectorCaptureImporter` e imprime somente o
resultado sanitizado (IDs de execução/revisão e contagens), nunca o payload.

Falhas retornam código 1 e mensagem genérica; uso inválido retorna código 2.
