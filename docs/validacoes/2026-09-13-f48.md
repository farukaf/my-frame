# F48 — skill de builds alinhada ao loadout

F48 atualiza `skills/warframe-builds/SKILL.md` para usar `get_loadout` como
visão principal de equipamento/configuração e `get_mods` para detalhar uma
instância. A skill continua separando fato observado de hipótese e não usa
`ConfigJson` ou IDs opacos para inventar polaridade, capacidade ou
compatibilidade.

## Validação

- as referências da skill apontam para ferramentas presentes no MCP;
- a saída exige instância, rank/config e cobertura antes de certificar uma
  build;
- lacunas permanecem `unverified`.
