# Validação F125 — regressão Core/MCP após a cadeia de hardening

Após F119–F124, as suítes determinísticas foram executadas separadamente para
evitar o paralelismo excessivo do agregador da solução:

```text
MyFrame.Core.Tests: Passed 159, Failed 0, Skipped 0
MyFrame.Mcp.Tests:  Passed 18,  Failed 0, Skipped 0
```

Comandos:

```powershell
dotnet test MyFrame.Core.Tests/MyFrame.Core.Tests.csproj --no-build --no-restore -v:minimal
dotnet test MyFrame.Mcp.Tests/MyFrame.Mcp.Tests.csproj --no-build --no-restore -v:minimal
```

O gate agregado da solução não é declarado nesta evidência porque a execução
paralela iniciou muitos workers dotnet no ambiente local; os dois projetos
foram validados diretamente e concluíram sem falhas.
