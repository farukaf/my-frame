# Validação F130 — sincronização manual do Public Export no App

F130 conecta os clientes `PublicExportIndexClient`/`PublicExportDocumentClient`
ao `SyncHost` no aplicativo. A página de status agora oferece **Sync Public
Export**, escolhe a entrada oficial de catálogo, publica de forma transacional
em SQLite e mantém a revisão anterior quando a tentativa falha.

Validação local:

```text
dotnet build MyFrame.App/MyFrame.App.csproj --no-restore -v:minimal -p:NoWarn=NU1900
Build succeeded. 0 Warning(s), 0 Error(s)
```

A chamada contra `origin.warframe.com` não é executada automaticamente nesta
validação; o botão é manual e a cobertura de rede/fonte real continua sujeita
à disponibilidade e política da fonte oficial.
