# Validação F203 — skills orientadas por cobertura rica

As skills de build e farm agora consultam a cobertura `public-export` antes de
usar componentes, relíquias, categoria de produto ou identidade de mercado.
Assim, a LLM recebe um procedimento explícito para reduzir a conclusão quando o
catálogo está parcial, em vez de interpretar ausência como zero ou inexistência.

## Evidências

- `warframe-builds` exige `components`/`productCategory` conhecidos antes de
  calcular requisitos.
- `warframe-farm` exige cobertura de componentes/relíquias antes de listar rotas
  e pré-requisitos.
- O contrato comum documenta `get_source_coverage("public-export")`.
- As regressões Core/MCP da F202 permanecem aprovadas: 180 Core e 20 MCP.

## Critérios

- [x] Skills referenciam a cobertura do catálogo.
- [x] Ausência de cobertura reduz a conclusão para hipótese/parcial.
- [x] Procedência e revisão continuam obrigatórias.
