# F106 — MCP Inspector CLI

F106 executa o [MCP Inspector](https://github.com/modelcontextprotocol/inspector)
contra o executável `MyFrame.Mcp` real, usando stdio e `tools/list --strict`.

## Execução

```powershell
pwsh -File .\scripts\Test-McpInspector.ps1
```

Resultado observado em 2026-09-13:

```text
MCP_INSPECTOR_OK=1
MCP_INSPECTOR_TOOLS=14
MCP_INSPECTOR_WARNINGS=163
MCP_INSPECTOR_ERRORS=0
MCP_INSPECTOR_METHOD=tools/list
```

O transporte, inicialização, encerramento e descoberta das ferramentas passaram.
Os 163 avisos são reais: o Inspector aponta schemas nullable emitidos como
`type: ["T", "null"]`, uma forma válida de JSON Schema, mas menos portátil para
clientes que esperam um único `type`. Eles ficam registrados como débito técnico;
F106 não os reclassifica como falhas nem afirma portabilidade total.

O script falha quando o Inspector retorna erro, não descobre ferramentas ou o
processo MCP termina com erro. A instalação do pacote é feita pelo `npx`; em CI
sem rede, o pacote deve estar no cache ou o job deve declarar explicitamente a
dependência indisponível.
