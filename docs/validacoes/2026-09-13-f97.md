# F97 — gate reproduzível do contrato MCP

F97 adiciona `scripts/Test-McpContract.ps1`, um gate único para a matriz MCP.
Ele compila o projeto de testes (salvo quando `-NoBuild` é usado) e executa a
suíte de stdio real, cobrindo descoberta, schemas, conteúdo estruturado,
paginação, cursores assinados, troca de snapshot/contexto, erros tipados,
filtros World State e o comportamento somente leitura.

Uso:

```powershell
pwsh -File .\scripts\Test-McpContract.ps1
pwsh -File .\scripts\Test-McpContract.ps1 -NoBuild
```

Validação executada:

- build sem erros;
- MCP: 14/14 testes;
- `MCP_CONTRACT_OK=1`;
- `git diff --check` aprovado.
