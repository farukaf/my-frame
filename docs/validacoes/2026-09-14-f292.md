# F292 — diagnóstico GEP visível na página de status

A página Sync status agora exibe os sinais sanitizados já disponíveis no Core e
MCP: estado interno do coletor, features suportadas, contagens por evento e
último callback. Nenhum payload ou identidade é incluído.

Quando a extensão estiver carregada, a homologação pode ser acompanhada pela UI
sem abrir arquivos de diagnóstico manualmente.
