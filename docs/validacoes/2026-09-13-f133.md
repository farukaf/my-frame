# Validação F133 — aliases localizados do Public Export

## Objetivo

Preservar nomes localizados fornecidos pelo catálogo oficial para que a
identidade consultável não dependa apenas do `name` em inglês.

## Alteração

- O parser aceita `name` ou `names` como string ou objeto de idiomas.
- O nome inglês continua sendo o campo primário quando disponível.
- Aliases são gravados em `public_export_items.aliases_json`.
- Bancos existentes recebem a coluna automaticamente; leituras antigas mantêm
  o fallback `en -> name/uniqueName`.
- O raw JSON continua preservado separadamente para campos ainda não modelados.

A alteração não inventa traduções: só persiste valores textuais presentes no
documento oficial e mantém a procedência no `raw_json`.
