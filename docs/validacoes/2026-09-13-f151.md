# Validação F151 — sincronização Public Export por arquivo local

`MyFrame.Sync --public-export-file <arquivo.json>` permite publicar um
Public Export previamente baixado, mantendo o mesmo parser, hash, revisão,
coverage e publicação transacional do caminho HTTP. Isso fornece um caminho
operacional quando o proxy/rede bloqueia o endpoint oficial, sem reintroduzir
AlecaFrame nem aceitar catálogo não validado.

O arquivo é limitado a 64 MiB, deve ser um array JSON compatível com o contrato
Public Export e recebe o parser version `public-export-file-1`.

Exemplo:

```powershell
dotnet run --project .\MyFrame.Sync -- --public-export-file .\fixtures\ExportWeapons_en.json --data-root .\artifacts\sync-file-test
```

O fluxo reaproveita staging, hash, revisão ativa e coverage do SQLite. O teste
de regressão cobre a publicação por fixture; a execução com fonte oficial real
continua dependente de obter o arquivo fora do proxy bloqueado.
