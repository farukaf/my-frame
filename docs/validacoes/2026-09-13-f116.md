# F116 — credencial WFM protegida por usuário Windows

F116 adiciona `ProtectedFileMarketTokenStore`, usando DPAPI com escopo
`CurrentUser`. O App passa a usar esse store; leitura de token plaintext legado
continua disponível sem reescrita automática, enquanto `SaveAsync` grava apenas
payload protegido. O segredo não entra no SQLite, logs ou MCP.

Evidências:

```text
ProtectedCredentialStoreTests: 2 passed, 0 failed
```

O fluxo de login/renovação/revogação do Warframe.Market ainda requer uma tela ou
integração de autenticação explícita; esta fase fecha somente o armazenamento
seguro e independente do AlecaFrame.

Os builds Windows foram bem-sucedidos. O ambiente local reportou `NU1900` ao
consultar o serviço de vulnerabilidades NuGet por proxy indisponível; isso não
produziu erro de compilação nem falha de teste.
