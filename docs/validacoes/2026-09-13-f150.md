# Validação F150 — gate de runtime baseado em heartbeat

O readiness gate não exige mais que o nome da extensão apareça nos logs do
Overwolf quando há um heartbeat recente `collector-status.json`. A evidência de
log continua sendo emitida para diagnóstico, mas não é uma dependência rígida:
o heartbeat é produzido pela própria UI da extensão ao iniciar a captura.

O gate ainda exige, de forma independente, Overwolf, Warframe, manifest válido e
ao menos um marker `.ready.json`. Assim, um heartbeat isolado não declara uma
captura homologada.

Execução atual (antes de carregar a extensão):

```text
OVERWOLF_PROCESS=1
WARFRAME_PROCESS=1
COLLECTOR_MANIFEST=1
COLLECTOR_EXTENSION_LOGGED=0
COLLECTOR_HEARTBEAT=0
COLLECTOR_RUNTIME_EVIDENCE=0
CAPTURE_MARKERS=0
OVERWOLF_COLLECTOR_READY=0
```
