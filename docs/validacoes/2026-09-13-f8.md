# F8 — capacidades e status no MCP

## Entregue

- ferramenta somente leitura `get_capabilities`;
- ferramenta somente leitura `get_sync_status`;
- registro de dez ferramentas no contrato (oito v1 + duas de descoberta);
- capacidades distinguem disponível, parcial, opcional, import-only e validação externa pendente;
- status consulta SQLite em modo read-only e não inicia rede, migração ou escrita;
- fontes sem revisão retornam `not_initialized`;
- instruções e schema do recurso MCP orientam o cliente a consultar capacidades/status antes de dados específicos.

## Limite

As ferramentas de domínio ricas (inventário por instância, atividades e referências) ainda estão sendo integradas incrementalmente. As ferramentas v1 existentes continuam preservadas; este PR não remove nem altera seus contratos.

## Validação

- build de `MyFrame.Mcp` sem erros;
- metadados das novas ferramentas permanecem read-only, idempotentes, não destrutivos e não open-world;
- suíte Core: 120 testes passando antes da adição apenas de código MCP.

O projeto de testes MCP atualiza a expectativa de oito para dez ferramentas. A execução do assembly MCP permanece pendente porque o build/test runner com RuntimeIdentifier deixa processos dotnet vivos e bloqueia a saída; esse comportamento precisa ser resolvido no CI/runner.
