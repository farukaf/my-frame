# Validação F135 — status operacional via CLI

O `MyFrame.Sync --status` consulta o SQLite sem rede, UI ou AlecaFrame e retorna
um JSON sanitizado para as fontes `public-export`, `worldstate-pc` e
`overwolf-inventory`.

Verificação em diretório temporário vazio:

```text
dotnet build MyFrame.Sync/MyFrame.Sync.csproj --no-restore -v:minimal -p:NoWarn=NU1900
Build succeeded. 0 Warning(s), 0 Error(s)
--status => JSON com dataRoot e status null para as três fontes
```

O estado `null` representa ausência de tentativa registrada; não é convertido em
sucesso nem em inventário vazio.
