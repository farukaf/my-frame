# F3 — Public Export: primeiro adaptador

## Entregue neste incremento

- parser de índice tolerante a hash antes/depois do caminho;
- rejeição de caminhos absolutos e traversal;
- parser de documentos JSON em lista com `uniqueName`, nome, categoria e descrição;
- normalização de identidade sem acentos para comparação PT/EN, sem transformar o nome em chave primária;
- cliente HTTP com limite de 4 MiB e decoder de LZMA injetável.

## Limite deliberado

O endpoint oficial `index_en.txt.lzma` é comprimido. O projeto não interpreta bytes comprimidos como texto: a implementação exige um decoder injetado e lança `PUBLIC_EXPORT_LZMA_DECODER_NOT_CONFIGURED` quando ele não está configurado. Assim não há publicação silenciosa de conteúdo corrompido. A escolha do decoder/licença e o download dos arquivos referenciados continuam sendo a próxima parte da F3.

## Validação

| Caso | Resultado |
| --- | --- |
| índice com hash-first e path-first | aprovado |
| traversal/drive path | rejeitado |
| documento sem campos opcionais | aprovado, campos permanecem desconhecidos |
| identidade com diacríticos e espaços | comparação aprovada |

Nenhum conteúdo externo foi versionado; os testes usam fixtures mínimos.
