# F3 — Public Export: primeiro adaptador

## Entregue neste incremento

- parser de índice tolerante a hash antes/depois do caminho;
- suporte ao formato oficial observado `arquivo.json!00_<tag>`;
- rejeição de caminhos absolutos e traversal;
- parser de documentos JSON em lista com `uniqueName`, nome, categoria e descrição;
- normalização de identidade sem acentos para comparação PT/EN, sem transformar o nome em chave primária;
- cliente HTTP com limite de 4 MiB e decoder LZMA-Alone integrado, injetável no cliente.
- cliente de documentos que produz `SyncBatch` com hash SHA-256 do payload baixado.
- publicação atômica de registros normalizados na tabela `public_export_items`;

## Limite deliberado

O endpoint oficial `index_en.txt.lzma` é comprimido. O decoder LZMA-Alone agora valida o header, limita a saída e rejeita UTF-8 inválido ou tamanho inconsistente. O cliente continua recebendo o decoder por injeção para manter o transporte testável. O download dos arquivos referenciados e a publicação no SQLite continuam sendo a próxima parte da F3.

Em 13/09/2026 o índice real foi baixado em memória e decodificado: 16 entradas,
incluindo `ExportWarframes_en.json!00_gFCc6M4iI-LF11CBMzq4FQ` e
`ExportWeapons_en.json!00_zwapa0tHPowLsyegwAU-zw`. O host dos documentos respondeu
HTTP 403 (`Access Denied`) para os arquivos individuais testados; não houve bypass.
Essa é uma limitação externa registrada, não uma publicação de catálogo incompleto.
