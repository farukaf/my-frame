# F111 — falha MCP sem escrita, rede ou vazamento

F111 envia `initialize`, `notifications/initialized` e uma chamada para uma
ferramenta inexistente usando um root de dados vazio. O harness exige resposta
JSON-RPC de erro, encerramento em até 15 segundos, zero sockets, root ainda
vazio e ausência de credenciais/caminhos locais no protocolo.

```powershell
pwsh -File .\scripts\Test-McpFailureReadOnly.ps1 `
  -ServerPath .\MyFrame.Mcp\bin\Debug\net10.0\win-x64\MyFrame.Mcp.exe
```

Resultado observado:

```text
MCP_FAILURE_READONLY_OK=1
MCP_FAILURE_NETWORK_CONNECTIONS=0
MCP_FAILURE_RESPONSES=2
MCP_FAILURE_ERROR_PRESENT=1
MCP_FAILURE_EXIT=0
```

Esse gate cobre falha de protocolo local; não substitui testes de rede bloqueada
em ambiente corporativo nem a homologação Overwolf.
