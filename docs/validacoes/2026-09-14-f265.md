# F265 — erro sanitizado no probe Public Export

O modo `--public-export-probe` agora retorna códigos estáveis (`PUBLIC_EXPORT_NETWORK_UNAVAILABLE`,
`PUBLIC_EXPORT_TIMEOUT`, `PUBLIC_EXPORT_INVALID_DATA`, `PUBLIC_EXPORT_UNSUPPORTED` ou
`PUBLIC_EXPORT_PROBE_FAILED`) em vez da mensagem literal da exceção.

Validação local:

```text
state=unreachable
source=public-export
errorCode=PUBLIC_EXPORT_NETWORK_UNAVAILABLE
EXIT=1
```

O gate `Test-PublicExportProbeReadOnly.ps1` também rejeita detalhes de proxy,
endereço local ou texto de transporte no stdout. O probe permanece sem criar
data root nem escrever SQLite.

Execução do gate:

```text
PROBE_STATE=unreachable
PROBE_EXIT_CODE=1
PUBLIC_EXPORT_PROBE_READONLY=1
```
