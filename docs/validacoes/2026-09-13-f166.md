# Validação F166 — diagnóstico seguro de indisponibilidade do Public Export

Uma tentativa real com data root temporário retornou falha de sincronização
porque o ambiente local não consegue acessar a rede (proxy recusado). O runner
antes colapsava esse caso em `SYNC_FAILED`; agora classifica qualquer erro de
transporte sem status HTTP como `PUBLIC_EXPORT_NETWORK_UNAVAILABLE`, sem
vazar host, proxy ou exceção para MCP/UI.

## Evidência

```text
SharedRunnerClassifiesTransportFailureWithoutLeakingNetworkDetails: Passed
Resultado local: state=failed, errorCode=PUBLIC_EXPORT_NETWORK_UNAVAILABLE
```

O teste usa um data root temporário; nenhum banco do usuário foi alterado.
