# Validação F156 — busca MCP de referências importadas

Foi adicionada a ferramenta read-only `search_references`. Ela lê somente
`<data-root>\references\*.json`, valida cada documento com
`ReferenceDocumentParser`, ignora arquivos inválidos com contagem explícita e
retorna snippets com tipo (Wiki/Overframe), URL, revisão, licença, autoria e
`trustedForFacts=false`.

Não há acesso à rede nem ingestão automática. O conteúdo continua separado dos
fatos do jogo e precisa ser importado com atribuição/licença permitidas.
