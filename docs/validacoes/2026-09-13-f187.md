# Validação F187 — ferramentas de inventário/cobertura presentes no MCP real

## Problema encontrado

O MCP publicado listava somente 17 ferramentas, embora a reflexão e os testes
contassem 23. As seis ausentes tinham retorno estruturado na raiz como
`IReadOnlyList<T>`; o SDK não as expunha no protocolo.

## Correção

Os seis retornos agora usam envelopes objeto com a propriedade `items`:

- `get_sync_history` → `SyncHistoryResponse`;
- `get_inventory_coverage` → `InventoryCoverageResponse`;
- `get_source_coverage` → `SourceCoverageResponse`;
- `get_equipment` → `InventoryEquipmentResponse`;
- `get_mods` → `InventoryUpgradesResponse`;
- `get_loadout` → `LoadoutResponse`.

## Evidência

Após rebuild do MCP Debug, `tools/list` retornou todas as 23 ferramentas,
incluindo as seis que estavam ausentes. O teste de nomes/read-only passou e o
build terminou sem erros (somente avisos `NU1900` de feeds de auditoria).
