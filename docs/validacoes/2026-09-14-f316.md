# Validação F316 — teste não vacuoso de IDs de fonte

O teste de cobertura que acompanha F313 foi fortalecido. Além de consultar
`" WARFRAME-MARKET "` em uma raiz sem revisão, ele cria uma referência Wiki
válida e consulta `" REFERENCES "`, verificando que pelo menos um DTO populado
retorna `SourceId=references` (canônico).

Assim a normalização é comprovada tanto no caminho vazio quanto no caminho com
dados observados; a consulta continua read-only.
