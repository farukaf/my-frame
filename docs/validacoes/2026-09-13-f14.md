# F14 — importação de captura validada para SQLite

## Entrega

`CollectorCaptureImporter` conecta o marker `.ready.json` validado ao
`SyncDatabase.PublishInventoryAsync`:

- verifica hash, tamanho, caminho, schema, IDs, encoding e payload antes de
  publicar;
- exige `allowRawPayload=true`, mantendo consentimento explícito para persistir
  o payload bruto;
- transforma o payload em `InventoryProjection`, preservando desconhecidos e
  estados `NotObserved`;
- publica de forma transacional e idempotente por content hash;
- rejeita payload opaco/não-objeto sem criar revisão;
- aceita BOM UTF-8 sem alterar o hash de integridade.

O probe continua somente leitura; a nova classe é a etapa explícita de ingestão
que pode ser chamada pelo host do coletor/app.
