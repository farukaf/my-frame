# F68 — prioridade SQLite sobre legado AlecaFrame

F68 remove a dependência operacional escondida no caminho principal: quando a
projeção SQLite contém inventário e catálogo, ela é usada mesmo que exista uma
pasta `lastData.dat` do AlecaFrame. O leitor legado continua disponível apenas
quando não há projeção sincronizada utilizável.

## Validação

- teste `PrefersSynchronizedDataWhenLegacyAlecaDataAlsoExists` fornece dados
  divergentes e verifica que somente a projeção SQLite aparece;
- Core 141/141;
- build Core sem warnings novos;
- fallback legado permanece coberto pelos testes existentes.
