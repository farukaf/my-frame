# F17 — inbox de captura e importação em lote

F17 adiciona `CollectorCaptureInbox`, uma operação reutilizável para o app, o
probe e futuros workers sincronizarem uma pasta de capturas `.ready.json`.

Garantias:

- exige `allowRawPayload=true` antes de enumerar/importar a inbox;
- valida cada marker pelo `CollectorCaptureImporter` existente;
- continua processando os demais markers quando um arquivo é inválido;
- não move nem apaga capturas privadas;
- diferencia `imported`, `alreadyPublished` e `rejected`;
- devolve somente nomes de marker, contagens e códigos de erro sanitizados;
- reimportação do mesmo marker é idempotente.

Validação: três testes Core cobrem consentimento, importação, rejeição parcial
e segunda execução idempotente. A integração com a UI/worker automático fica
para a próxima fase; F17 fornece o contrato seguro para essa integração.

O probe também expõe o contrato operacional em lote:

```text
MyFrame.Collector.Probe.exe --import-directory --directory <folder> --database <data.db> --allow-raw
```
