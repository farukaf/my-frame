# F263 — teste de regressão da comparação de inventário

Foi adicionado um teste de integração que publica duas revisões completas em
SQLite e verifica que `get_inventory_changes` detecta equipamento alterado e
stackable novo sem devolver payload privado.

O build dos projetos de produção (`MyFrame.Core` e `MyFrame.Mcp`) passou. Com
`NuGetAudit=false`, `--disable-build-servers` e `-m:1`, a suíte MCP completa
compilou e passou, incluindo os testes stdio e concorrência:

```text
Passed! Failed: 0, Passed: 24, Skipped: 0, Total: 24
```

Sem esses parâmetros o SDK 10.0.401 pode tentar resolver workloads e consultar
índices NuGet indisponíveis, causando uma falha/hang ambiental antes dos testes.

Isso não altera o contrato: a distribuição 0.0.22 já foi validada com o smoke
read-only e expõe a ferramenta nova.

Como gate de regressão da base compartilhada, `MyFrame.Core.Tests` também passou
com 185 testes (`Failed: 0, Passed: 185`).
