# Validação F182 — caso F10 Mother Token com revisão World State publicada

## Fixture e publicação

Foi criado um data root temporário e executado:

```powershell
MyFrame.Sync.exe --world-state-file docs/fixtures/worldstate-community-token.json \
  --data-root <temp>
```

Resultado: `state=published`, `records=1`, `parserVersion=worldstate-file-1`.
O root foi removido ao final; nenhum dado persistente do usuário foi alterado.

## Chamadas reais

Codex e Claude receberam o mesmo cenário isolado e chamaram:

```text
get_world_state({"reward":"Mother Token"})
```

Resposta MCP observada nos dois clientes:

- `state=available`;
- `coverage.bountyRewards/motherTokens/syndicateMissions=Known`;
- uma bounty `deimos-token` do sindicato Entrati;
- recompensa `Mother Token`, `count=5`, `chance=100`;
- revisão ativa presente;
- `activation` e `expiry` ausentes;
- ciclos não retornados.

Os dois clientes responderam que esta é a única opção listada no snapshot, mas
não afirmaram que é objetivamente a mais eficiente nem que está válida “agora”.
Também não inventaram tokens por hora.

## Limites

Esta é uma validação seeded do caso de World State, não o baseline F10 completo:
faltam os dois casos restantes, avaliação humana antes/depois e uma captura de
World State oficial com janela temporal real.
