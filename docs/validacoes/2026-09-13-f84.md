# F84 — proteção contra fallback em schema inválido

F84 adiciona uma regressão para garantir que uma resposta HTTP 200 com JSON
inválido falha como erro de parsing e não tenta a fonte comunitária. O fallback
continua restrito a falhas de transporte/timeout, preservando a detecção de
mudanças incompatíveis no contrato oficial.

Validação executada:

- fixture inválida gera `JsonException` sem segunda requisição;
- Core: 147/147;
- MCP: 13/13;
- App Windows build sem warnings ou erros.
