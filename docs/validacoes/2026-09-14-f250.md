# F250 — tentativa de ingestão real da Wiki

O executável distribuído 0.0.18 foi apontado para:

`https://wiki.warframe.com/w/Mother_Token`

O conector aplicou a allowlist, mas a requisição não pôde sair deste ambiente:

```text
state=failed
errorCode=No connection could be made because the target machine actively refused it. (127.0.0.1:9)
exit=1
```

Isso é uma falha de conectividade do ambiente, não uma aceitação da fonte nem uma
falha de validação do envelope. A referência só deve ser publicada quando uma
execução com rede autorizada retornar JSON atribuído e passar o parser.
