# F54 — filtro de sindicato no World State

F54 adiciona um filtro opcional, case-insensitive e exato por sindicato em
`get_bounties` e `get_world_state`. Isso permite que a LLM peça somente as
bounties relevantes para uma facção (por exemplo, `Entrati`) e combine o
resultado com o limite de 1–200 registros, sem inferir que uma lista vazia
significa ausência de conteúdo quando a fonte está indisponível.
