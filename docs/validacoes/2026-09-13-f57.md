# F57 — sincronização manual do World State

F57 liga a fonte World State ao fluxo de uso da aplicação. A página de status
agora oferece uma ação explícita que busca `https://api.warframestat.us/pc`,
valida e publica a revisão pelo `SyncHost`, atualizando o SQLite e mostrando a
revisão/quantidade publicada. Falhas são registradas pela fonte e preservam a
revisão anterior; a ação não é disparada pelo MCP nem por uma leitura passiva.

## Validação

- `dotnet build MyFrame.App/MyFrame.App.csproj --no-restore -v:minimal -m:1 -p:UseSharedCompilation=false` — 0 warnings, 0 errors;
- `dotnet test MyFrame.Core.Tests/MyFrame.Core.Tests.csproj --no-build -v:minimal` — 137/137;
- comando e estado de carregamento ligados ao `DashboardViewModel`;
- erro de rede não substitui nem apaga a revisão World State anterior.
