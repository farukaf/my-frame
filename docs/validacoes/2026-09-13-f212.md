# F212 — componentes Public Export normalizados no SQLite

## Objetivo

Materializar a primeira relação de receita do catálogo sem abandonar o JSON de
origem. Cada revisão Public Export agora grava `public_export_components`, ligada
à revisão e ao item pai, com identificador canônico, quantidade requerida, ducats,
tradabilidade, imagem e raw JSON do componente.

## Implementação

- schema SQLite evoluído para a versão 4;
- publicação transacional popula a tabela a partir de `components` válidos;
- retenção remove componentes junto com a revisão correspondente;
- `GetPublicExportComponentsAsync` lê somente a revisão ativa;
- itens sem componentes continuam válidos e não recebem relações inventadas.

## Validação

```powershell
dotnet test MyFrame.Core.Tests/MyFrame.Core.Tests.csproj --no-restore -v:minimal -m:1 -p:UseSharedCompilation=false
```

Resultado: Core 180 testes e MCP 21 testes aprovados. O teste de integração publica um item com
componente e verifica a relação normalizada e seus valores, além da projeção
existente pelo `SynchronizedDataReader`.
