# Validação F120 — desempenho com App e dois MCP

F120 adiciona um gate reproduzível para o cenário operacional pendente: fixture
de inventário grande, App ativo e dois servidores MCP consultados em paralelo.
O fixture passa pelo `CollectorCaptureImporter` real e não injeta tabelas
diretamente no SQLite.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Test-AppMcpPerformance.ps1
```

Resultado observado em 13/09/2026:

```text
APP_MCP_PERF_OK=1
APP_MCP_PERF_FIXTURE_ITEMS=20000
APP_MCP_PERF_SERVERS=2
APP_MCP_PERF_APP_ALIVE=1
APP_MCP_PERF_ELAPSED_MS=4712
APP_MCP_PERF_RESPONSE_BYTES=5816
APP_MCP_PERF_WORKING_SET_BYTES=113565696
```

O resultado registra quantidade de itens, latência total dos dois calls, bytes
de respostas e working set amostrado. O gate comprova o caminho operacional e
deve ser executado em máquina de referência para estabelecer limites; não é uma
afirmação de qualidade de resposta da LLM nem substitui a captura F1 real.
