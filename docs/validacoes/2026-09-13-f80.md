# F80 — identificação automática da fonte World State

F80 faz o `WorldStateClient` gravar a versão do parser coerente com o endpoint
usado: `worldstate-official-1` para a URL da Digital Extremes,
`worldstate-community-1` para WarframeStat.us e `worldstate-1` para fixtures ou
hosts desconhecidos. O valor segue para `source_revisions.parser_version` e fica
visível em `get_sync_status` por F79.

Validação executada:

- cliente fixture rotulado contra os dois endpoints;
- Core: 145/145 testes;
- MCP: 13/13 testes;
- build sem warnings nem erros.
