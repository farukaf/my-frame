# F246 — smoke real dos clientes no MCP 0.0.17

Codex e Claude foram executados contra o servidor `my-frame` configurado para
`artifacts/MyFrame-0.0.17-win-x64/MyFrame.Mcp.exe`. Cada cliente chamou uma única
vez `get_capture_inbox_status` em modo read-only.

Ambos descobriram e executaram a ferramenta, retornando os mesmos campos:

```json
{"state":"not_initialized","overwolfRunning":true,"warframeRunning":true,"heartbeatFresh":false,"validMarkers":0,"invalidMarkers":0}
```

Isso comprova o transporte stdio e o contrato distribuído em clientes reais. Não
comprova F1: a extensão unpacked ainda não foi carregada no Overwolf, portanto não
há heartbeat nem marcadores de captura.
