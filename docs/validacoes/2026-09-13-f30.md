# F30 — cobertura do inventário no MCP

O MCP agora oferece `get_inventory_coverage`, que lê a projeção SQLite e
retorna `fieldPath`/`state` ordenados. Estados `NotObserved`, `Invalid` e
`NotSupported` continuam explícitos; a ferramenta não converte ausência em
quantidade zero e não expõe payload bruto.

O contrato passa a ter 13 tools read-only, idempotentes e com schema estrito.
Validação: build MCP e suíte stdio devem ser executados após recompilar os
assemblies de teste.
