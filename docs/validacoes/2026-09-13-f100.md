# F100 — gate operacional de processo MCP somente leitura

F100 amplia `scripts/Test-McpReadOnly.ps1` para observar sockets TCP do processo
MCP durante a inicialização, além de confirmar encerramento por EOF, stdout vazio
e data root limpo.

Execução:

```powershell
$server = (Resolve-Path .\MyFrame.Mcp\bin\Debug\net10.0\win-x64\MyFrame.Mcp.exe).Path
pwsh -File .\scripts\Test-McpReadOnly.ps1 -ServerPath $server
```

Resultado observado:

```text
MCP_READONLY_OK=1
MCP_NETWORK_CONNECTIONS=0
MCP_EXIT=0
```

O gate não substitui uma política de firewall ou auditoria de produção; ele prova
que o processo MCP não abriu sockets TCP na inicialização e não gravou no data
root limpo. Sincronizações de rede permanecem responsabilidade do App/SyncHost.
