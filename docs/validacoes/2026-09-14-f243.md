# F243 — warning de captura ausente no snapshot SQLite

## Alteração

Quando o snapshot sincronizado contém inventário, mas o probe Overwolf não está
em `ready`, o Core agora adiciona `INVENTORY_CAPTURE_UNVERIFIED` aos warnings.
Os dados históricos não são apagados nem tratados como vazios; a resposta MCP
passa a declarar explicitamente que posse atual precisa ser confirmada no jogo.

## Validação

- Core/MCP regressão executada após a alteração;
- aviso não expõe payload, caminho ou processo;
- captura em `ready` não recebe esse warning.
