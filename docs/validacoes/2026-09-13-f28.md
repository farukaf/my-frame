# F28 — gate MCP read-only

Foi criado `scripts/Test-McpReadOnly.ps1 -ServerPath <MyFrame.Mcp.exe>`.
O script inicia o servidor distribuído com `MYFRAME_DATA_ROOT` temporário,
fecha stdin imediatamente, exige encerramento em até 15 segundos, exige exit 0,
stdout vazio antes de uma requisição e nenhum arquivo criado no data root.

Execução esperada:

```text
MCP_READONLY_OK=1
MCP_EXIT=0
```

O gate cobre EOF/encerramento e ausência de escrita em armazenamento limpo. Não
substitui uma medição de rede bloqueada ou uma sessão MCP Inspector/clientes
reais, que permanecem gates separados.
