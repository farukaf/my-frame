# F46 — estado de disponibilidade de bounties

F46 envolve a resposta de `get_bounties` com `state`, `lastAttemptAt` e
`errorCode`. Isso evita interpretar uma lista vazia como “não existem
bounties” quando o World State ainda não foi sincronizado ou falhou.

Estados de dados continuam separados da lista: `available` indica uma última
publicação bem-sucedida; `not_initialized`, `failed` e outros estados exigem
que o cliente consulte o diagnóstico antes de recomendar farm.

## Validação

- chamada stdio em data root sem World State retorna `not_initialized`;
- conteúdo estruturado mantém a lista vazia sem apagar o diagnóstico;
- Core: 137 e MCP: 12 testes aprovados.
