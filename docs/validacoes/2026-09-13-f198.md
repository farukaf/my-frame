# Validação F198 — endpoint oficial versionado do Public Export

O cliente do Public Export foi alinhado ao formato oficial de distribuição:

- índice: `https://origin.warframe.com/PublicExport/index_en.txt.lzma`;
- documentos: `https://content.warframe.com/PublicExport/Manifest/<arquivo>!<revisionTag>`;
- o `revisionTag` opaco retornado pelo índice é preservado na URL do documento.

Isso corrige o `PUBLIC_EXPORT_HTTP_404` observado quando o cliente buscava o
documento diretamente em `/PublicExport/` sem o segmento `/Manifest/`.

## Evidências

```text
dotnet build MyFrame.Core.Tests/MyFrame.Core.Tests.csproj --no-restore -v:minimal
Build succeeded

dotnet vstest MyFrame.Core.Tests/bin/Debug/net10.0/MyFrame.Core.Tests.dll \
  --TestAdapterPath:MyFrame.Core.Tests/bin/Debug/net10.0 \
  --TestCaseFilter:"FullyQualifiedName~PublicExportTests"
Passed: 17, Failed: 0

MyFrame.Sync.exe --public-export --data-root <temporário>
state=failed
errorCode=PUBLIC_EXPORT_NETWORK_UNAVAILABLE
```

O último comando confirma que o fluxo chega ao transporte, mas a rede desta
execução recusou o proxy local. A homologação com dados reais continua pendente
até uma execução com acesso ao endpoint oficial.
