# F117 — serviço local de credencial WFM

F117 adiciona `MarketCredentialService`, que classifica credenciais sem expor o
valor, valida `exp` do JWT antes de salvar, grava pelo store DPAPI e permite
revogação local. O serviço é registrado no App; o MCP não recebe esse serviço.

Evidências:

```text
CredentialService tests: 2 passed, 0 failed
```

O contrato cobre armazenamento/status/revogação. Login, renovação remota e a
tela de entrada do token continuam pendentes e não são simulados por fixtures.
