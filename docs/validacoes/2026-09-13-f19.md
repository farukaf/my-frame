# F19 — falhas da inbox persistidas no SQLite

F19 conecta rejeições individuais da inbox ao histórico de sincronização:

- cada marker inválido continua sendo rejeitado sem interromper os demais;
- `sync_runs` recebe uma tentativa `failed` para `overwolf-inventory`;
- somente um código sanitizado (`CAPTURE_INTEGRITY_FAILED`, `CAPTURE_FORMAT_INVALID`, etc.) é persistido;
- nenhum trecho do payload ou caminho local é gravado no erro;
- a página de status e o MCP passam a enxergar a falha mesmo após reiniciar o app.

Validação: Core 126/126, incluindo a asserção de `LastRunState=failed` e do
`ErrorCode` após uma captura adulterada.
