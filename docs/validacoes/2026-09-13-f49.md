# F49 — paridade World State SQLite→MCP

F49 amplia o teste stdio do MCP para semear uma revisão World State com uma
bounty Entrati, um job e a recompensa Endo. A chamada `get_bounties` deve
retornar `available` e os mesmos valores observados na projeção SQLite.

Isso cobre o caminho de integração sem depender de rede ou do processo do jogo;
não substitui o ensaio do coletor GEP real.

## Validação

- build MCP sem warnings;
- 12/12 testes MCP aprovados;
- resposta estruturada contém `available`, `Entrati` e `Endo`.
