# F103 — memória de dois processos MCP

F103 adiciona `scripts/Test-McpConcurrent.ps1`, um harness Windows que inicia
dois `MyFrame.Mcp.exe` reais com data roots distintos, mede `WorkingSet64` por
PID, encerra ambos por EOF e verifica stdout vazio e ausência de arquivos.

Execução:

```powershell
$server = (Resolve-Path .\MyFrame.Mcp\bin\Debug\net10.0\win-x64\MyFrame.Mcp.exe).Path
pwsh -File .\scripts\Test-McpConcurrent.ps1 -ServerPath $server
```

Resultado observado:

```text
MCP_CONCURRENT_OK=1
MCP_CONCURRENT_SERVERS=2
MCP_WORKING_SET_BYTES=80891904
MCP_WORKING_SET_MAX_BYTES=40873984
```

Os valores são uma medição da máquina local, não um limite universal; devem ser
coletados novamente na máquina de referência antes do release.
