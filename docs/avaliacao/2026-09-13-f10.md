# F10 evaluation protocol

Evaluate LLM answers before and after the relevant skills using the same snapshot,
model, temperature, and output limit. Two reviewers classify each requirement as
`pass`, `fail`, or `unknown`.

Each case must record the snapshot, tool calls, source revisions, coverage, uncertainty,
and critical failures. Do not include tokens, personal paths, raw inventory, or account
identity in results.

Run the structural checker with:

```powershell
./scripts/Test-F10Evaluation.ps1
```

The evaluation is not complete until real capture and permitted source gates allow the
required evidence. See [the delivery checklist](../../todo.md).
